## 1 技术栈 / 播放 / ASR / 扩展

### 1.1 技术栈

原生 **Swift + SwiftUI**（`ShadowEdge/*.swift` 路径成片），`@Observable`（`_$observationRegistrar`）。无 Flutter/RN。`Frameworks/` 目录不存在 → 依赖静态链接。

静态链接的关键库：
- `GRDB`（`GRDB_GRDB.bundle`、`grdb_migrations`、GRDB 内部错误串）
- `GoogleSignIn`（`GIDSignIn`、`GoogleSignIn_GoogleSignIn.bundle`、`com.google.gtmappauth`）
- `Firebase App Check`（`GACAppCheckProvider`、`com.firebase.app_check.app_attest_artifact_storage`、`AppAttest`）——**仅用于 Google 登录的 client_assertion**（见 3.3 说明）
- **Rust 内核**：二进制中大量 `/rustc/31fca3ad.../library/...` 与 `src/phonology.rs`、`src/scoring/*` 路径，以及 `PhonologyFile`/`ContextRuleRaw`/`RealizationRule` 结构 → 发音评分/音系规则引擎是 Rust 写的，编进主二进制

系统框架：`AVFoundation / AVKit / Accelerate / CoreML / CoreMedia / Charts / CryptoKit / DeviceCheck / LocalAuthentication / SafariServices / WebKit / UserNotifications / StoreKit / SystemConfiguration`。

### 1.2 播放实现

- `AVPlayer` + `AVKit`（跟读片段播放、AB 循环、变速）
- `WKWebView`：`webapp.shadowedge.app/m/`（移动网页端，用于网页订阅/账户管理），`ShadowEdge/ChangePlanWebView.swift` 注入 `window.localStorage.setItem('shadowedge.session.v1', ...)` + `/billing/success`
- 无第三方播放器 SDK

### 1.3 ASR / 评分实现（本地 + 云端双引擎，这是本案最关键的结构）

**端上评分引擎（不耗额度）**
- `LocalScoringEngine`、`LocalScoreResult`、`LocalWordResult`、`DeviceScore`、`ScoringPreferences`
- CoreML 模型下发：`https://models.lingovea.com/phoneme/ios/manifest.json` + `ModelDownloader` / `ModelAssetStore` / `ModelPreparationState`（本地键 `app.shadowedge.modelDownload`）
- Rust 引擎输出结构（直接来自二进制字段表）：
  `accuracy_score, fluency_score, prosody_score, completeness_score, overall_score, word, phonemes, poken, score, error_type, start_ms, end_ms`
- **`scoring_mode`: `full | partial | fluency_only`** ← 三档评分颗粒度，UI 文案 "You're seeing fluency only. Premium unlocks per-word accuracy, phoneme-level pronunciation hints, and prosody scoring" 正对应 `fluency_only`
- 路由开关（UserDefaults 键）：`localScoring.enabled`（Bool）、`localScoring.routing` ∈ `whenCloudUnavailable | always`；模型清单 `https://models.lingovea.com/phoneme/ios/manifest.json`
- 本地引擎失败文案佐证其独立性：`The recording could not be decoded for on-device scoring.`、`The on-device scoring model is not installed.`

⇒ 把 `localScoring.routing` 设成 `always` 后，评分完全在本机跑；此时 `scoring_mode` 由客户端按 `allow_phoneme_scoring` 决定 → **改档位即可拿到 full 模式的逐词/音素/韵律，且一个字节都不上行**。

**云端转写 / 云端评分（吃额度）**
- `POST /media/v2/api/sources/upload`（presigned 直传，头：`X-Goog-Upload-Protocol/Command/Offset` 或 `x-amz-checksum-sha256`）→ 返回 `recordingId` / `recordingKey` / `uploadUrl`
- `/transcription/{reset|retry|skip}`、`/media/v2/api/transcription/languages`
- `SessionWebSocket`（实时转写/评分回流）
- `/scoring/v2/api/scoring_requests/`、`/scoring/v2/api/recordings/`、`/scoring/v2/api/segments/`、`/scoring/v2/api/me/usage`

## 4 可解锁分级

**综合结论：UI + 端上评分 = B（偏 B+）；云端评分/转写 = C。**

### A 级（纯本地判定）
- **端上音素评分（CoreML + Rust）**：模型本地、推理本地、`scoring_mode` 由客户端选择 → 若把 `allow_phoneme_scoring` 打开，`fluency_only → full` 的逐词/音素/韵律反馈**完全离线可用，且不消耗任何服务端额度**。
- 词表/生词本、播放器（AB 复读、变速）本身无门。
- 但"档位从哪来"仍需服务端，所以纯 A 只覆盖"引擎能力"，不覆盖"入口"。

### B 级（服务端下发、客户端自行放行）—— **主战场**
证据链（四条，互相印证）：
1. `tier` 是 `APIUserProfile` 的一个字符串字段，客户端把它映射成 `UserTier` 枚举后**自己**决定 UI（`PaywallTierCard`、`PaywallView`）。
2. 配额对象里有 `allowed` / `remainingToday` / `remainingThisMonth`——这是**客户端计算**出来的布尔，不是服务端逐次下发的许可票据。
3. `shadow_tier_features` 是完整能力矩阵（14 个 `allow_*` / `*_per_*` 键），一次性下发、客户端缓存使用。
4. 消费侧的拒绝文案是客户端的（`You've reached your plan's limit for new sources this week.`、`Your current plan can't upload video.`），说明拦截发生在请求发出**之前**。

⇒ 改写 `/account/v2/api/me` 的 `tier` → `platinum`、`/billing/v2/api/me/billing/summary` 的 `shadow_tier_features` 全 `allow_*: true`、`*_per_*` 放大、`/billing/v2/api/me/usage` 的 `used: 0`，即可把 UI 层与端上评分全开。

原文门禁文案（`en.lproj/Localizable.strings` 直引，证明拦截发生在客户端）：
```
You're seeing fluency only. Premium unlocks per-word accuracy, phoneme-level pronunciation hints, and prosody scoring...
Phoneme-level feedback is a Pro feature. Upgrade to see exactly which sounds to refine.
You've used up today's practice time. Upgrade for more, or come back tomorrow.
You've reached your plan's limit for new sources this week. Upgrade to add more.
Your current plan can't upload video. Upgrade to a higher plan to upload video files.
This file is too large for your current plan. Upgrade to upload bigger files.
Recording exceeds your plan's per-clip limit.
Fastest and private. Your cloud scoring quota isn't used.        ← 端上评分的官方卖点
For takes longer than your plan's cloud limit, or once the daily or monthly cloud quota is used up.
```

### C 级（服务端强校验/计量）
- **云端评分与云端转写**：服务端按 `uid` 记 `scores_today` / `scores_this_month`，超出直接拒；计数不在客户端。
- **购买**：`signed_transaction` 由服务端向 App Store Server API 验签，并把 `originalTransactionId` 绑定 `uid`（`transaction_owned_by_other_account` / `transaction_user_mismatch`）→ 伪造/复用票据不可行。
- **上传与存储**：presigned URL 由服务端签发，`upload_per_file_bytes` / `total_storage_bytes` 服务端校验。

⇒ 云评分额度、云转写时长、大文件上传，Loon 改不动。

## 5 务实落点

### 5.1 Loon（改 `api.lingovea.com`，三条 URL）

```
[Host]
api.lingovea.com

[Script]
http-response ^https:\/\/api\.lingovea\.com\/(account|billing)\/v2\/api\/(me|me\/billing\/(summary|usage)) script-response-body https://your.gw/se_unlock.js

[Rewrite]
^https:\/\/api\.lingovea\.com\/account\/v2\/api\/me(\?.*)?$ url script-response-body https://your.gw/se_unlock.js
^https:\/\/api\.lingovea\.com\/billing\/v2\/api\/me\/billing\/summary url script-response-body https://your.gw/se_unlock.js
^https:\/\/api\.lingovea\.com\/billing\/v2\/api\/me\/usage url script-response-body https://your.gw/se_unlock.js
```

脚本要点：

```js
// 1) /account/v2/api/me
body.tier = "platinum";                       // 或 goldLifetime / platinumLifetime（终身档 UI 最干净）
body.entitlements = body.entitlements || [];
if (!body.entitlements.includes("phoneme_scoring")) body.entitlements.push("phoneme_scoring");

// 2) summary.shadow_tier_features —— 必须全量给，缺键会走 fallback 到 free
const feat = {
  cloud_score_count_per_day: 9999, cloud_score_count_per_month: 99999,
  cloud_per_clip_seconds: 3600,   total_per_day_seconds: 86400,
  source_per_week: 999,           upload_per_file_bytes: 5368709120,
  total_storage_bytes: 1099511627776, sync_daily_limit: 9999,
  video_download_count_per_month: 9999,
  allow_video_upload: true, allow_video_download_360p_720p: true,
  allow_video_download_1080p: true, allow_priority_cloud_queue: true,
  allow_phoneme_scoring: true
};
Object.assign(body.shadow_tier_features || (body.shadow_tier_features = {}), feat);

// 3) /billing/v2/api/me/usage
body.used = 0; body.scores_today = 0; body.scores_this_month = 0;
body.remaining = body.cap = 999999;
body.resets_at = new Date(Date.now() + 30*864e5).toISOString();
```

注意点：
- `tier` 用了 `platinumLifetime` 反而可能触发"管理订阅"页的 web 跳转；日常用 `platinum` + 把 `renews_at` 推到未来更稳。
- `shadow_tier_features` 是**全量替换语义**：只给部分键，客户端会按缺失项回落 free。
- 会话是 Keychain 存的 Bearer，Loon 不需要碰 token，只需在 `Authorization` 已带上的响应上做替换。
- 云端评分仍会被服务端按 uid 计数拒绝（`403`/`402`），此时 App 会提示额度用尽——**这是 C 级绕不过的硬边界**。

### 5.2 额度制结论（说清楚）

**Shadow Edge 是"服务端记账 + 客户端自行放行"的混合体：**
- 数字来源：服务端（`scores_today`、`scores_this_month`、`used/cap/remaining`、`resets_at`）
- 放行判定：客户端（`allowed` = capability − usage，本地算）
- 消耗记账：服务端（云端评分/转写按 uid 计）

所以：**UI、功能入口、端上 CoreML/Rust 评分（含 full 模式的逐词/音素/韵律）可以靠 Loon 完全打开**；**云端转写/云评分时长绕不过**。这不是"假解锁"——端上评分是货真价实的本地推理，只是入口被 `allow_phoneme_scoring` 卡住。

### 5.3 若走本地补丁（越狱/TrollStore）

优先级：
1. Hook `APIUserProfile` / `UserTier` 的 decode（把 `tier` 强制成 `platinum`，`shadow_tier_features` 全 true）——一处覆盖全 UI。
2. 或 Hook `EntitlementGate.allowed` 的 getter（返回 true）。
3. 绝不 hook `StoreKit`（`signed_transaction` 服务端验签，改了只会 401）。
4. 纯 SwiftUI + `@Observable`，别用传统 OC `%hook` 类布局（会崩），走 Swift 符号钩 / LoadControl 弱加载。
