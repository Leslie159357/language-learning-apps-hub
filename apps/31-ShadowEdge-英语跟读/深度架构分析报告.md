# 31-ShadowEdge 深度架构分析报告

## 一、技术栈与播放内核

- **基础规格**：应用 Bundle ID 为 `com.goshadowing.shadowedge`，版本号 `1.1.6`，最低系统要求 iOS `17.0`。主二进制体积 `11.24 MB`，无独立动态库。
- **技术栈**：采用原生 Swift 与 Objective-C 混合架构，持久化依托 GRDB.swift（SQLite），认证与安全依赖 Google Sign-In 及 Firebase App Check，本地 AI 推理依托 Apple CoreML 框架。
- **播放与音视频内核**：媒体播放基于 `AVFoundation` 封装出 `AudioPlayer` 与 `FullscreenPlayerView`，底层调用 `AVPlayer`、`AVPlayerItem`、`AVPlayerViewController` 与 `AVAudioPlayer`；用户录音独立由 `RecordingPlayer` 负责回放；音频采样与格式重采样由 `AVAudioConverter`、`AVAudioPCMBuffer`、`AVAudioFile` 与 `AVAudioApplication` 协同处理。

## 二、模块分层

1. **表现层（UI / Views）**：由 SwiftUI 与 UIKit 协同呈现。主要视图包括 `ContentView`、`FullscreenPlayerView`、`WordPracticeView`、`WordPracticeBreakdownSheet`、`InstallModelSheet`、`LibraryView`、`AccountView`。
2. **状态与业务会话层（ViewModels & Coordinators）**：管理练习流程、媒体会话与账号。核心类为 `PracticeViewModel`、`WordPracticeViewModel`、`OnDeviceScoringViewModel`、`LibraryViewModel`、`AuthViewModel`、`MediaPlaybackSession`、`AppRouter`。
3. **端侧 AI 音素评测引擎（CoreML & Scoring）**：
   - 模型运行时：`CoreMLPhonemeModel`、`PhonemeModel`、`MLModel`、`MLModelConfiguration`。
   - 资产分发与存储：`ModelDownloader`、`ModelAssetStore`、`PhonologyAssetStore`。
   - 评分服务：`DeviceScoreService`、`WordScoringService`。
4. **音频录制与语音服务**：`AudioRecorder`、`RecordingService`、`WordSpeechService`、`SpeechVoiceCatalog`。
5. **网络、安全与存储层**：`NetworkService`、`AuthService`、`StoreKitService`、`GACAppCheckAPIService`、`GACAppAttestAPIService`、`DatabaseMigrator`、`FetchableRecordDecoder`、`GTMKeychainStore`。

## 三、能力模块

- **视频导入与解析**：支持精选片单库与用户添加源（`AddSourceSheet.swift`、`AddSourceViewModel`、`CurationRequestsView`），由 `MediaPlaybackSession` 调度播放会话。
- **字幕与词汇**：提供生词弹窗与卡片（`WordActionPopover.swift`、`WordEdgeLink.swift`）；支持单词发音维度拆解（`WordPracticeBreakdownSheet.swift`）；点词词典由系统 `UIReferenceLibraryViewController` 与 `MLDictionaryFeatureProvider` 承接。
- **跟读与端侧评分**：
  - **音频采集与转换**：`AudioRecorder` 通过 `AVAudioRecorder` 录制音频，经由 `AVAudioConverter` 将音频流转化为 CoreML 模型所需的 PCM 特征输入。
  - **端侧音素打分**：调用 `CoreMLPhonemeModel` 进行音素级本地推理，由 `DeviceScoreService` 计算发音得分；模型资产支持云端动态下载更新（`ModelDownloader`、`InstallModelSheet`）。
  - **对照回听**：`RecordingPlayer` 与 `WordSpeechService`（基于 `AVSpeechSynthesizer`）提供自录发音与系统标准音比对。
- **云盘/协议接入**：未包含 WebDAV、SMB 等云盘协议，专注精选跟读教学媒体流。
- **媒体库管理**：通过 `LibraryView`、`LibraryViewModel`、`MediaHistoryStore`、`CurationStore` 管理跟读历史、收藏片单与练习进度。

## 四、网络与 API 契约

- **自有域名与 Web 端点**：
  - `shadowedge.app`、`webapp.shadowedge.app`、`www.shadowedge.app`、`app.shadowedge.io`。
  - 端点：`https://webapp.shadowedge.app`、`https://webapp.shadowedge.app/m/`、`https://www.shadowedge.app/legal/privacy`、`https://www.shadowedge.app/legal/terms`。
- **核心业务依赖（Lingovea 架构）**：
  - **业务 API**：`https://api.lingovea.com`（用户账户、内容片单与学习打卡同步）。
  - **模型分发与词库**：`https://models.lingovea.com`（CoreML 语音模型权重下载）、`https://wordedge.lingovea.com/deck`、`https://id.lingovea.com/region-policy`、`https://community.lingovea.com/`。
- **安全与鉴权**：
  - Google / Firebase：`https://firebaseappcheck.googleapis.com/v1`（App 完整性校验）、`https://www.googleapis.com/oauth2/v4/token`。

## 五、对自研的参考价值

1. **端侧 CoreML 音素评分架构**：完全在端侧部署 `CoreMLPhonemeModel` 并结合 `DeviceScoreService` 实现音素级细粒度打分，杜绝了语音录音上传带来的网络延迟和用户隐私泄露风险，并消除了云端 ASR 评测 API 成本。
2. **模型分发与安装解耦**：将体积较大的 CoreML 权重文件剥离出主安装包，通过 `ModelDownloader` 与 `ModelAssetStore` 实现云端下发与按需装载，使 App 主二进制能够轻量化保持在 11 MB 左右。
3. **App Check 与设备认证防护**：引入 `GACAppCheckAPIService` 与 `GACAppAttestAPIService`，在调用敏感接口及下载专有模型资产前校验客户端合法性，有效防止模型资产与后端数据被逆向窃取。
