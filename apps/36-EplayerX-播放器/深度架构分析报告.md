# EplayerX 深度架构分析报告

## 1. 播放内核与渲染实现
EplayerX 采用基于 KSPlayer 的高度模块化多媒体播放架构，支持双内核动态路由切换：
- **双内核实现（AVPlayer 与 KSMEPlayer）**：针对标准封装格式走原生硬解 KSAVPlayer 与 ProAVPlayer；针对复杂音视频流走基于 FFmpeg 深度定制的 KSMEPlayer（由 MEPlayerItem、MEPlayerItemTrack、PlaybackMeOption 与 AbstractAVIOContext 驱动）。
- **MetalFX 超分放大与 HDR 渲染**：视频渲染依托 MetalPlayView 与 MetalRender，集成了 Apple 官方 MetalFX 技术的超分辨率缩放器 MetalFXScaling.swift、SDR 转 HDR 渲染器 SDRToHDRRenderer.swift，以及全景流光背景特效 AmbientMetalBackgroundView 和 AmbientMetalFrameScheduler。
- **高级音频处理管线**：建立多层次音频引擎架构，包含 AudioEnginePlayer、AudioGraphPlayer、AudioRendererPlayer、AudioUnitPlayer、AudioNoiseDetector 以及空间音频转码器 SpatialAudioTranscode 和对象音频混音计划 ObjectAudioMuxPlan，支持基于 AVAudioEngine 的均衡器与实时变调。
- **字幕渲染系统**：通过 AssImageRenderer、AssIncrementImageRenderer、AssParse、MetalSubtitleView 实现 ASS 特效字幕的 GPU 增量光栅化渲染，并配合 AppleSubtitleTranslator 提供系统级实时字幕翻译。

## 2. 模块分层结构
- **媒体库与刮削管理层（MediaLibrary / Scrape / Metadata）**：负责海量影视库的整理与元数据抓取。核心类包括 MediaLibraryViewController、MediaLibraryBrowseViewController、MediaLibraryDetailController、MediaLibraryEditorController、MediaScrapeCoordinator、MediaScrapeMatcher、TMDBDetailStore 与 TVDBMetadataShowsViewController。
- **播放核心与音频图形层（KSPlayer / Audio / Metal）**：负责播放器状态机与音视频解码呈现。核心类包括 KSVideoPlayer、KSVideoPlayerView、KSAVPlayer、KSMEPlayer、KSCorePlayerView、AudioEnginePlayer、AudioGraphPlayer、MetalPlayView、MetalRender、SDRToHDRRenderer 与 MetalFXScaling。
- **云端存储与网盘协议层（CloudDrive / NetworkShare / Crawler / Emby）**：承接文件系统与远程服务器。核心类包括 BaiduDriveClient、BaiduDriveAuthentication、BaiduDriveBrowserProvider、CloudDriveBrowserViewController、CloudDriveCatalogProvider、CloudDriveMountStore、CloudDriveRequestGate、CloudDrivePageCache、NetworkShareProvider、EmbyHomeService、EmbyItemsService、EmbyFavoritesService 与 CrawlerDiscoverService。
- **UI 与沉浸交互层（HomeFeed / PlayerChrome / BottomControls）**：负责海报瀑布流、播放器控制栏与详情抽屉。核心类包括 HomeRootViewController、HomeFeedController、HomeFeedCarouselCell、HomeFeedBackdropView、NativePlayerViewController、PlayerSettingsSheetViewController、PlayerDanmakuSearchPanel、PlayerSubtitleSearchPanel 及 BottomControlsView+NativeMenus。

## 3. 协议与云盘接入
- **局域网共享与流媒体服务**：支持基于 SMB 的网络共享（NetworkShareProvider、NetworkShareEditorViewController），深度支持 Emby 媒体服务器集群（EmbyHomeService、EmbyFavoritesService、EmbyMultiResumeService、EmbyChartStore），并接入 Plex 认证与资源发现（app.plex.tv/auth#?、plex.tv/api/v2/）。
- **云盘驱动接入**：全面对接百度网盘（BaiduDriveClient、BaiduDriveAuthentication、BaiduDriveRenameViewController，覆盖 pan.baidu.com 与 openapi.baidu.com）、广雅网盘（www.guangyapan.com/oauth/、openapi-account）、规则爬虫引擎（CrawlerDiscoverService、CrawlerHomeManageViewController）以及社区规则块（CommunityBlockStore）。
- **OAuth 鉴权域名与回调**：
  - 自建后端回调中转：https://api.eplayerx.com/oauth/baidu/callback。
  - 百度开放平台：https://openapi.baidu.com/oauth/2.0/authorize 与 openapi.baidu.com/oauth/2.0/token。
  - 广雅网盘：https://www.guangyapan.com/oauth/。
  - Plex：https://app.plex.tv/auth#? 与 https://metadata.provider.plex.tv。

## 4. 网络与 API 契约
- **自建中心化服务端**：自有 API 矩阵包含 api.eplayerx.com 与 tmdb.eplayerx.com。其中 api.eplayerx.com 承载百度网盘 OAuth 授权回调与 AI 字幕生成服务（/subtitles/deepseek/v1），tmdb.eplayerx.com 承担 TMDB 元数据代理中转；eplayerx.com 负责分发规则配置（/import/blocks）。
- **AI 智能字幕契约**：直接集成 DeepSeek API（api.deepseek.com、/subtitles/deepseek/v1）与 OpenAI/Google Gemini 接口（api.openai.com/v1、generativelanguage.googleapis.com/v1beta/openai），支撑字幕自动翻译与字幕提取。
- **影视信息与弹幕聚合契约**：聚合 TheIntroDB 跳过片头（api.theintrodb.org/v3/media）、Trakt 观影进度追踪（api.trakt.tv 与 auth.trakt.tv）、弹弹play 弹幕服务（api.dandanplay.net）、射手网字幕检索（api.assrt.net/v1 与 www.shooter.cn/api/subapi.php）及 OpenSubtitles（api.opensubtitles.com/api/v1）。
- **商业化内购订阅**：集成 RevenueCat 订阅体系（api.revenuecat.com、api-paywalls.revenuecat.com）。

## 5. 对自研的参考价值
- **双播放内核优雅结合模式**：基于 KSPlayer 架构实现 KSAVPlayer（原生节能硬解）与 KSMEPlayer（FFmpeg 兼容软解）的统一封装，面对常规流享受原生解码的极低功耗，面对多音轨、ASS 复杂特效或特殊封装格式时无缝退回软解管线。
- **下一代 Metal 画面增强技术（MetalFX + SDR转HDR）**：引入 MetalFXScaling 超分辨率算法与 SDRToHDRRenderer，在 iOS/macOS 移动端设备上通过 Metal 着色器低功耗实现画质拉伸与高动态范围重建。
- **网盘请求网关与流缓存控制**：设计 CloudDriveRequestGate 与 CloudDrivePageCache，为网盘流媒体播放建立前置门禁控制与分页缓存预拉取，显著降低网盘直链在快速拖拽时的请求震荡与卡顿。
