# SenPlayer 深度架构分析报告

## 1. 播放内核与渲染实现
SenPlayer 采用基于 mpv 与 FFmpeg 的底层多媒体架构，并在源文件树中完整内嵌了 mpv 核心实现（包含 source/player/video.c、source/player/audio.c、source/sub/osd_libass.c、source/sub/ass_mp.c、source/video/hwdec.c 及 shaders/custom_mpv.c），结合 libavcodec、libavfilter、libavformat、libswresample 与 libswscale。
- **硬件解码**：通过 libavcodec/videotoolbox.c 与 source/video/hwdec.c 调用 Apple VideoToolbox 完成硬解。
- **HDR 与渲染管线**：视频渲染层构建在 Metal 基础之上，封装了 CoreRenderView、CorePlayerView 与 CAMetalLayer，并通过 MetalHDRVividMapper、MetalSDRToHDRMapper、MetalSpatialUpscaler 和 MetalVideoDeinterlacer 实现 HDR Vivid 映射、SDR 转 HDR、超分辨率放大与去隔行处理。
- **音轨直通**：底层包含 ad_spdif.c 实现 S/PDIF 压缩数字音频直通，音频输出通过 ao_audiounit.m 接入系统 AudioUnit，配合上层 AVSampleBufferAudioRenderer 与 AVAudioSession 处理声道映射与路由中断。

## 2. 模块分层结构
基于逆向类名与源文件，系统呈现清晰的四层架构：
- **媒体库层（MediaLibrary / CoreData）**：负责资产索引、分类管理与播放记录存储。核心类包括 DetailProvider、MLibListView、EmbyFavoritesView、MediaFile、MediaRecord、MediaVerify、FMix、SeriesTrackRule 与 MainChildLoad。
- **播放器层（MediaPlayer / Render / Core）**：封装播放调度与图像渲染。核心类包括 Player、PlayerControl、CoreRuntime、NextPreloader、CorePlayerView、CoreRenderView、FrameOutputRenderTarget、SPFFmpegAssetTrack 与外挂播放器控制器 ExternalPlayerController。
- **网络与协议层（ServerCore / Kit / FileProvider）**：承接远程服务与云盘数据流。核心类包括 DriverConnector、ServerProvider、CloudFileProvider、AMSMB2Manager、SambaIOContext、FFmpegIOContext、EmbyClient、EmbyUtil、PlexResource。
- **UI 与交互层（AppRoot / MainViews / BaseView）**：构建用户操作界面。核心类包括 RootController、RouterView、ServerListView、DriveFileView、NasFileView、IPTVView、VideoControlView、IOSGestureView、FileObjMenu、DriveQrLoginView。

## 3. 协议与云盘接入
- **局域网与流媒体协议**：集成 SMB（基于 AMSMB2Manager 与 SambaIOContext）、WebDAV（WebDAVFileProvider）、Emby（EmbyClient、EmbySubtitleSources）以及 Plex（PlexResource、ServerListView+Plex）。
- **云盘驱动接入**：实现多网盘适配器，包括阿里云盘（AliyunDriveConnector）、百度网盘（BaiduPanConnector）、115网盘（Drive115Connector）、123云盘（Drive123Connector）、广雅云盘、Dropbox（DropboxFileProvider）、OneDrive（OneDriveFileProvider）、Google Drive、Box 与 pCloud。
- **OAuth 鉴权域名与重定向**：
  - 115网盘：passportapi.115.com/open/authorize，设备码接口 passportapi.115.com/open/authDeviceCode，重定向至 https://www.senapp.top/redirect_115 与 https://www.senmuse.com/redirect_115。
  - 百度网盘：openapi.baidu.com/oauth/2.0/authorize 与 openapi.baidu.com/oauth/2.0/device/code。
  - 阿里云盘：open.aliyundrive.com/oauth/authorize 与 openapi.alipan.com。
  - 123云盘：open-api.123pan.com/api/v1/oauth2/access_token 与 yun.123pan.com/auth。
  - 广雅网盘：openapi-account.guangyapan.com/v1/auth/device/code。
  - Dropbox：https://www.dropbox.com/oauth2/authorize，重定向至 https://www.senapp.top/redirect_dropbox。
  - Plex：https://app.plex.tv/auth#?clientID=。

## 4. 网络与 API 契约
- **自有业务服务端**：自建日志上报服务 https://www.senmuse.com/api/logs（由 LogUploadManager.swift 驱动）；利用 www.senapp.top 承接各网盘 OAuth 授权回调分发。
- **第三方聚合契约**：Trakt 观影进度同步（api-staging.trakt.tv 与 staging.trakt.tv）、弹弹play 弹幕获取（api.dandanplay.net）、豆瓣搜索元数据补全（m.douban.com/search/）。
- **直链拉取契约**：百度 PCS 直链与分片下载契约（d.pcs.baidu.com/rest/2.0/pcs/superfile2，配额接口 pan.baidu.com/api/quota）；115 采用设备码轮询契约（deviceCodeToToken 与 refreshToken）。

## 5. 对自研的参考价值
- **统一云盘 Connector 抽象**：通过 DriverConnector、CloudFileProvider 与 CloudItem 建立标准化接口，将鉴权、目录拉取与下载直链解析统一封装，新增网盘仅需实现独立 Provider。
- **流式 IO 挂载管道**：自研 FFmpegIOContext 与 SambaIOContext，把 SMB 协议与网盘 HTTP 直链转换为统一的 IO 流直接灌入 mpv/FFmpeg 解复用管道，解耦存储协议与播放内核。
- **GPU 渲染后处理链**：将 HDR Vivid 映射、SDR 转 HDR 及空间放大独立成 Metal 处理算子（MetalHDRVividMapper、MetalSpatialUpscaler），无需在解码阶段重复转码，大幅降低能耗。
