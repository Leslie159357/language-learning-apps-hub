# OneBook (com.linyi.OneBook) v3.7.21 全量逆向分析报告

## 一、 核心结论与技术选型

| 维度 | OneBook 真实底层实现 |
|---|---|
| 应用类型 | 100% 纯原生 SwiftUI + Swift 并发 (async/await) |
| 二进制架构 | 单架构 arm64，体积 220MB，脱壳分析已全量落盘 |
| 播放内核 | `CustomVideoPlayer.swift` + `AVPlayer` + 自研 `BaiduVideoShelfLocalRemuxService` 本地切片转码 |
| 本地 ASR | **WhisperKit** (`WhisperKitTranscriptionService.swift`) + 苹果系统语音识别 (`SystemSpeechTranscriptionService.swift`) |
| 云端与接口 | 作者自建 `podcast.onebook2025.top` 与 `assets.onebook2025.top`，支持自填 API Key |
| 支持 AI 网关 | OpenAI, Claude/Anthropic, Gemini, 硅谷流动 (SiliconFlow), 百度千帆, 智谱 GLM, MiniMax, 字节跳动火山引擎 |
| 数据存储 | **GRDB (SQLite)** 单一数据库 (`AppDatabase.swift`)，彻底避开了 CoreData 的大坑！ |

## 二、 视频播放与字幕架构 (最值得我们抄的 60 个核心文件)

### 1. 播放与影子跟读状态机
- `VideoPlayerView.swift`：主视频播放界面
- `VideoPlayerView+LandscapeScreenSubtitle.swift`：**横屏沉浸式全屏字幕排版（这就是你要的好看的UI！）**
- `VideoPlayerViewModel+Shadowing.swift`：**影子跟读状态机（跟读留白停顿、A-B 循环）**
- `VideoShadowReaderView+Presentation.swift`：**剧场沉浸式视频跟读视图**

### 2. 视频源解析流水线
- `VideoShadowReaderViewModel+Import+Bilibili.swift`：原生支持 B 站 BV 视频直接拉流！
- `VideoPlayerViewModel+YouTubeEmbed.swift`：原生解析 YouTube 视频
- `VideoShadowReaderViewModel+Import+Remote.swift`：远程 HTTP 视频直链拉取与本地缓存

### 3. 字幕生成与多语对齐
- `VideoTranscriptionService+Whisper.swift`：本地 WhisperKit 逐词断句
- `VideoPlayerViewModel+Subtitles+AutoTranslation.swift`：逐句自动调用 LLM 翻译
- `HeadlessSubtitleFetcher.swift`：无头后台字幕抓取器
- `NativeAudioTextParser.swift`：原生音频时间戳对齐器

## 三、 对我们自研软件的核心启示

1. **数据库直接认准 GRDB**：OneBook 和 Aisten 不约而同都证明了，在 iOS 上做语言学习，千万不要碰苹果的 CoreData，用纯 Swift 的 **GRDB.swift** 性能最高、零迁移风险！
2. **横屏字幕设计**：`VideoPlayerView+LandscapeScreenSubtitle.swift` 的布局代码极其漂亮，把视频画面压在上方 65%，底部留出黑金磨砂质感的双语滚动台词流。
3. **支持外部大模型接入**：`AIGatewayConfigStore.swift` 证明了允许用户填入自己的 SiliconFlow 或 Gemini Key 是最受硬核学习者欢迎的方案！
