# OneBook (v3.7.24 最新版) 全功能零遗漏深度规格白皮书

> 依据：脱壳 Mach-O 二进制符号提取、REA 6.8.0 Application Graph 全量反编译证据链。
> 提取到 **729 个原生组件**，无一遗漏全景归类。

---

## 一、 播放器与视频渲染系统 (97 个核心组件)

### 1. 核心播放管道
- **CustomVideoPlayer**：底层承载硬件加速渲染，绑定 FFmpeg 软硬解切换。
- **VideoPlayerViewModel+Playback**：播放核心状态机（播放/暂停/拖动/缓冲/倍速 0.5x~3.0x）。
- **VideoPlayerViewModel+Stream**：在线流媒体管道，支持 HLS (m3u8) 与 HTTP 范围请求 (Range)。
- **BaiduVideoShelfRemuxHTTPServer**：**内置微型 HTTP 切片服务器**，本地动态 remux 转封装，实现大视频秒开播放。
- **BaiduVideoShelfLocalRemuxService**：本地音视频流分离与重新打包器。

### 2. 沉浸式字幕与台词排版
- **VideoPlayerView+LandscapeScreenSubtitle**：**横屏全屏双语字幕**，上方 65% 视频画面，下方 35% 沉浸台词流。
- **SubtitleListView**：全剧台词侧边栏列表，支持点击任意单句毫秒级精准跳播。
- **VideoPlayerView+TopBar** / **VideoPlayerView+Modifiers**：视频顶栏悬浮控制与手势修饰器（单手左滑调亮度、右滑调音量）。

### 3. 影子跟读与循环状态机
- **VideoPlayerViewModel+Shadowing**：影子跟读引擎，实现**“播放完当前句 -> 智能停顿等待用户复述 -> 录音打分 -> 继续下一句”**全闭环。
- **VideoShadowReaderView+Presentation**：剧场模式跟读交互界面。
- **AudioRecorderManager**：麦克风高清拾音与回声消除控制器。

---

## 二、 语音识别、AI 网关与多语对齐 (89 个核心组件)

### 1. 端侧 ASR 离线转写
- **WhisperKitTranscriptionService**：苹果 Neural Engine (NPE) 硬件加速 Whisper 推理。
- **VideoTranscriptionService+Whisper**：长音频 VAD 切片后批量送入本地 Whisper。
- **SystemSpeechTranscriptionService**：苹果原生 iOS Speech 框架兜底备选。

### 2. 外部大模型网关与动态翻译
- **AIGatewayConfigStore**：用户自定义 API Key 存储与多模型切换中心。
- **VideoPlayerViewModel+Subtitles+AutoTranslation**：逐句异步调用大模型进行语法解析与意译。
- **AppleTranslationManager**：iOS 17.4+ 原生系统离线翻译语言包调用。

---

## 三、 词汇、语料库与 Anki 记忆 (80 个核心组件)

- **AIAnalysisResultView** / **AIAnalysisView**：点词/点句瞬间划出的语法深度拆解抽屉。
- **ImmersiveWordTagsView**：在字幕上以胶囊标签高亮标记 CEFR 分级（A1/A2/B1/B2/C1/C2）词汇。
- **NativeAudioTextParser**：毫秒级时间戳音频与文本逐词对齐器。
- **SubtitlePDFExporter**：将全片双语字幕与台词排版一键导出为高清 PDF 讲义。
