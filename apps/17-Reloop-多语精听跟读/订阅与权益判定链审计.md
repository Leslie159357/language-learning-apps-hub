## 1. 技术栈与架构

- **纯 SwiftUI 单二进制**：`Frameworks/` 目录不存在（IPA 内 `/Frameworks/` 路径 0 命中），SPM 全部静态链接进主二进制（13.9 MB），无自带 dylib。链接的全是系统库：`libswiftCore`、`AVFoundation`、`MediaPlayer`、`StoreKit`、`WebKit` 等。
- **ObjC 面极小**：`__objc_classlist` 仅 299 个类 / 2,001 个方法（对比同批 eusoft 应用 3,635 类 / 65,705 方法），业务逻辑在 Swift 层。Swift 源文件名以 "View.task @ file:line" 字面量形式残留在 `__cstring`，可直接读出模块结构：
  `TranscriptionManager.swift`、`TranscriptionStatusClient.swift`、`TranscriptionStatusPoller.swift`、`ReceiptPrintView.swift`、`PlayerView+Subtitles.swift`、`ReadAloudView.swift`、`WordPopupView.swift`、`SubtitleSearchView.swift`、`YouTubePlaylistDetailView.swift`。
- **扩展**：1 个 `PlugIns/StudyReminderNotificationContent.appex`（学习提醒通知内容扩展，无网络/无 StoreKit）。
- **三方件**：Mixpanel（`MixpanelEvents.md` 随包）、YouTubeKit / YouTubePlayerKit（`youtubekit-remote.losjet.com`、`www.youtube.com`）、MarkdownUI、SwiftUIIntrospect、NetworkImage。
- **随包 StoreKit 配置**：`Payload/podcastLearning.app/PodcastLearning.storekit` —— 这是开发期 StoreKit Configuration 文件，直接把全部 SKU 暴露出来（见 §2）。
- **音频资源**：包内有 40+ 个以人名命名的 mp3（`Adélie.mp3`、`Amara.mp3`、`Minseo.mp3`…），对应多语种跟读音色；`UIBackgroundModes = [audio, remote-notification]`。
- 关键架构判断：**AI 转录不在端上跑**。`TranscriptionStatusClient` / `TranscriptionStatusPoller` 的存在 + 包内无任何模型文件（无 `.mlmodelc`、无 onnx）说明转录是「上传/提交 → 轮询任务状态」的服务端流水线；包内 `pipeline.qiniu.com`、`/v4/query?ak=…&bucket=…` 进一步印证对象存储 + 处理流水线。

### 2.4 服务端 entitlement 下发路径

`https://api.reloopai.app` + 以下路径（`__cstring` 全量提取，均为 `^/[a-z...]$` 形式字面量）：

```
/user/quota/check          ← 额度闸门（无 token → HTTP 401）
/sentence/explain          ← 逐句讲解（会员/额度）
/sentence/explain/question ← 追问
/translate/sentence        ← 整句翻译
/v2/word/translate         ← 单词翻译
/x/player/playurl          ← 播放地址下发
/youtube/video/links       ← YouTube 链接解析
/v1/sdk/config             ← 统计 SDK 配置（sdk_name/sdk_version）
/v4/query?ak=…&bucket=…    ← 七牛流水线查询
```

实测：`POST https://api.reloopai.app/user/quota/check` → **401**（需登录态 Bearer）；`/v1/sdk/config`、`/x/player/playurl` 无参数 → 404 `404 page not found`（Go 风格，路径存在但方法与参数不符）。

## 4. 可解锁面分级

| 级 | 内容 | 证据 | 结论 |
|---|---|---|---|
| **A** | 本地订阅态（6 个 UserDefaults 键 + `Transaction.currentEntitlements`） | 键注册表 xref 0x100624F58；StoreKit 导入符号；`app_has_local_subscription` | 改 `user_is_subscribed=true` 只能让「我的」页显示会员、抑制买断弹窗。**拿不到额度**：转录发起后由 `TranscriptionStatusPoller` 轮询服务端任务，服务端按账号额度拒绝。属"皮"。 |
| **B** | `/user/quota/check` 响应体字段 | 路径存在但 401；未见包内明文 key | 理论上若把 `remaining`/`limit` 抬大，UI 会放行"开始转录"按钮；但真正扣费与任务创建在服务端，**不产生可用额度**。技术上可写，收益为零，且响应结构未验证。 |
| **C** | 转录 / 逐句讲解 / 翻译 / TTS 实际能力 | `/sentence/explain`、`/translate/sentence`、`/v2/word/translate`、`transcription` 轮询链；包内无模型文件 | 服务端执行 + 服务端计量。**重写无意义**。 |

**总判定：主付费墙 = C（服务端额度/服务端任务）。** 唯一 A 面是 UI 订阅态，不构成功能解锁。与 Infuse/Spotify 那类"本地 flag 即全部权限"的应用不同，Reloop 把额度做成了服务端计数器。

## 5. 务实落点

### 5.1 如果要写 Loon 插件（结论：不建议，收益为 0）

可注入点（域名 `api.reloopai.app`）：

```ini
[mitm]
hostname = api.reloopai.app

[rewrite_local]
# 额度查询：把已用清零（字段名需先抓包确认，以下是结构占位）
^https:\/\/api\.reloopai\.app\/user\/quota\/check url script-response-body reloop_quota.js
```

```js
// reloop_quota.js —— 仅影响客户端展示，服务端额度不变
let body = $response.body;
try {
  let o = JSON.parse(body);
  // 结构未验证：QuotaCheckRequest -> UserQuotaUsageResp
  // 常见形态：{ remaining: n, used: m, limit: l } 或 { transcription: {...} }
  const zero = (obj) => { for (const k in obj) {
    if (/^(used|usedSeconds|usedCharacters|consumed)$/i.test(k)) obj[k] = 0;
    if (/^(remaining|left)$/i.test(k) && typeof obj[k] === 'number') obj[k] = 999999;
    if (obj[k] && typeof obj[k] === 'object') zero(obj[k]);
  }};
  zero(o);
  $done({ body: JSON.stringify(o) });
} catch (e) { $done({}); }
```

**为什么没用**：`/user/quota/check` 只回答"还剩多少"，真正执行转录的是服务端任务（`TranscriptionStatusClient` 提交 → `TranscriptionStatusPoller` 轮询）。服务端在**创建任务时**校验额度；`subscription.error.verify_failed` / `transaction_verify_failed` 说明购买态也由服务端复核。

### 5.2 卡点

1. `/user/quota/check` 无 token 直接 401，必须先有登录态才能抓响应体 → 字段名无法在静态阶段确认（本 dossier 不给猜测字段名）。
2. 转录产物走七牛 `pipeline.qiniu.com` + `/v4/query`，产物 URL 带签名，改页面无用。
3. 若要真解锁，唯一路径是伪造服务端 entitlement —— 超出 Loon 能力边界。

### 5.3 若做本地补丁（非 Loon）

TrollStore/dylib 注入可 hook：
- `UserDefaults.standard.bool(forKey: "user_is_subscribed")` → 恒 true
- `SubscriptionManager.isSubscribed`（Swift，需按 mangled 名定位）

效果上限 = A 级：UI 显示会员、去广告位，**AI 额度仍为 0**。不建议投入。
