## 1. 技术栈与架构

- **React Native + Expo（bare/预构建）**。证据：`Frameworks/React.framework`、`Frameworks/ReactNativeDependencies.framework`、`Frameworks/hermesvm.framework`；`Expo.plist` 内含 `EXUpdatesCheckOnLaunch=ALWAYS` 与 OTA 代码签名证书（CN=LinguoLand OTA），即 **JS 逻辑可 OTA 热更**——任何端上写死的判定都可能在下次启动被替换。
- JS 层为 Hermes 字节码（非明文 JS），逻辑不可直读，但**字符串表完整可读**，接口路径/i18n key/错误码全部可提取。
- **IAP 走 OpenIAP**：`openiap-versions.json` = `{"spec":"2.1.0","google":"2.3.0-rc.1","apple":"2.2.5"}`；Bundle 内有 `kit.openiap.dev` 引用。原生侧无自研 StoreKit 封装类（ObjC/Swift 类表 899 类 / 4,511 方法，几乎全是 RN/Expo 基建 + 少量业务模块）。
- **无 App Extension**（IPA 内无 `.appex`）。
- URL Scheme：`linguoland`、`com.linguoland.app`；`NSUserActivityTypes` + `CFBundleDocumentTypes`（可导入外部图书）。
- 业务形态（从 i18n key 反推）：**credits（积分）+ 月度额度** 模型，而非"买断/订阅解锁内容"。关键 key：`quota.monthlyCeil`、`quota.monthlyTail`、`quota.monthlyExceeded`、`quota.monthlyWords`、`credits.reason.*`、`credits.meter.campaignEndsAt`、`term.lifetimeSlots`、`LIFETIME_SOLD_OUT`、`membership.lifetime`、`GUEST_FORBIDDEN`。

## 2. 付费墙判定链

### 2.1 商品与计费模型

- **包内无任何硬编码 SKU**：`app.linguoland.*`、`com.linguoland.app.*` 只匹配到 `com.linguoland.app.solomon`（渠道 flavor）与 `com.linguoland.app.developer`（开发标识），**不是产品 ID**。产品由服务端下发或由 OpenIAP apple 侧动态查询。
- 计费单位是 **credits**：`/api/v1/credits/apple-iap/verify`（Apple 收据校验入账）、`/api/v1/credits/alipay/{precreate,orders}`（支付宝，Android/网页）、`credits-ledger` 页。
- 消耗能力枚举（服务端 `topupRates` 直接给出）：`ENRICH`（语境/释义增强）、`TRANSLATE`（翻译）、`CHAT`（AI 对话）。

### 2.2 判定链（服务端为准，客户端只读）

```
启动 → POST /api/v1/auth/guest-init {deviceId}  → access_token
     → GET  /api/v1/auth/quota-status           → tier / quotas / cost / membership
     → GET  /api/v1/auth/me-snapshot-v2         → 用户快照
     → 读 /v1/subscriptions/status | /v1/subscriptions/entitlements   （订阅态）
     → 购买：OpenIAP → Apple → POST /api/v1/credits/apple-iap/verify  → 服务端入账
     → 用 AI 能力：POST /api/v1/ai/{chat-stream,translate-stream,enrich-stream,sentence-analysis-stream-b64}
```

`quota-status` 的真实响应（**由 guest-init 取得访客 token 后实测，2026-11-01**）：

```json
{"tier":"GUEST",
 "quotas":{"ENRICH":{"limit":20,"used":0,"remaining":20,"resetAt":"2026-11-01T16:00:00.000Z"},
           "TRANSLATE":{"limit":12,"used":0,"remaining":12,"resetAt":"…"},
           "CHAT":{"limit":8,"used":0,"remaining":8,"resetAt":"…"}},
 "cost":{"ceilingCents":100,"usedCents":0,"remainingCents":100,"resetAt":"…"},
 "topupRates":{"ENRICH":3,"TRANSLATE":2,"CHAT":1},
 "membership":{"paidUntil":null,"daysLeft":null,"isLifetime":false}}
```

即 **entitlement 字段名 = `tier` / `membership.paidUntil` / `membership.isLifetime` / `quotas.<CAP>.remaining` / `cost.remainingCents`**，无任何本地镜像。Bundle 内**不存在** `isPremium`/`hasAccess` 之类的本地开关字符串（全量检索仅 1 次 `entitlement`，即上表接口路径）。

### 2.3 本地标记

几乎没有。检索 `UserDefaults`/`AsyncStorage` 形态的键，只找到：
- `linguoland.ota_notes.frontier_date`（OTA 提示）
- `isGuestTier`（判断当前是否访客，取值来源于服务端 `tier`，不是可写开关）

结论：**没有可改的本地 entitlement**。

## 3. 网络面

| 域名 | 用途 |
|---|---|
| `api.linguoland.com` | NestJS 业务后端（错误体 `{"message":…,"statusCode":…}`，`Cannot GET` 风格确证） |
| `cdn.linguoland.com` | 静态资源：字体 zip、封面、`catalog-covers/`、语言资源 |
| `read.linguoland.com` | 阅读器 Web 侧 |
| `www.linguoland.com` | 法务页（terms/privacy） |
| `linguo-land.oss-cn-hangzhou.aliyuncs.com` | **图书正文存储（公开 OSS）** |

关键接口（全部实测）：

| 方法 | 路径 | 无凭证结果 |
|---|---|---|
| GET | `/api/v1/app/latest-version` | **200**（公开版本公告） |
| POST | `/api/v1/auth/guest-init` | **200**（body 必须含 ≥16 位 `deviceId`） |
| GET | `/api/v1/auth/quota-status` | 401 → 带 guest token **200** |
| GET | `/api/v1/catalog/collections/` | 401 → 带 guest token **200**（16 个集合） |
| GET | `/api/v1/catalog/collections/13` | 200（含 `items[]` 完整书目） |
| GET | `/api/v1/reading-progress/by-shelf-entry/{id}` | 403 `{"message":"无权访问该条目"}` |
| GET | `/v1/subscriptions/status` \| `/entitlements` \| `/bind-user` | 404（该 host 未挂载此组路由，或仅在网关另一前缀） |
| POST | `/api/v1/auth/me-snapshot-v2` | 404（同上，路径来自 HBC 串池，前缀可能不同） |

**决定性的内容侧发现**：`catalog/collections/{id}` 的 `items[]` 元素**没有任何付费/权限字段**（无 `isPremium`、无 `creditCost`、无 `accessLevel`），只有：

```json
{"id":1,"kind":"BOOK","title":"Welcome to LinguoLand Reader","format":"TXT",
 "storageKind":"EXTERNAL_URL",
 "storageRef":"https://linguo-land.oss-cn-hangzhou.aliyuncs.com/catalog/d28f2206-….txt",
 "translationsRef":null,"inlineText":null,"sizeBytes":2568,"license":"PROPRIETARY", …}
```

对该 OSS URL 直接 `curl`（**不带任何 token**）：
- `.txt` → `HTTP 200`，2,568 B
- `.epub` → `HTTP 200`，599,939 B

即**图书正文零鉴权**，谁都能下载。所谓"付费墙"不落在内容上。

## 4. 可解锁面分级

| 级 | 内容 | 证据 | 结论 |
|---|---|---|---|
| **A** | 无 | 全量检索无本地 entitlement 键；`isGuestTier` 只是服务端 tier 的镜像 | 没有纯本地开关可撬 |
| **B** | `/api/v1/auth/quota-status` 响应体 | 字段已实测：`tier`、`membership.isLifetime`、`quotas.*.remaining`、`cost.remainingCents` | 改写后客户端不再弹"额度用尽"、UI 显示无限；但 AI 请求到 `/api/v1/ai/*` 时服务端仍按账号扣费/拒绝（`QUOTA_EXCEEDED`、`GUEST_FORBIDDEN` 错误码在串池中）。**只能骗 UI。** |
| **C** | AI 能力（ENRICH / TRANSLATE / CHAT） | 服务端 `topupRates` 定价、`credits` 账本、流式接口全在服务端 | 重写无意义 |
| **特例** | 图书内容 | `storageKind=EXTERNAL_URL` + 公开 OSS 200 | **本来就没有付费墙**，不需要解锁；"会员可读全书"是营销话术，正文可直接下载 |

**总判定：无内容付费墙；付费墙 = AI 积分（C）。** Loon 能做的只有 B 级 UI 欺骗 + 直接取正文（不需要 Loon，curl 即可）。

## 5. 务实落点

### 5.1 想读全书：不需要任何插件

```bash
TOKEN=$(curl -s -X POST -H 'Content-Type: application/json' \
  -d '{"deviceId":"dossierprobe0000000001"}' \
  https://api.linguoland.com/api/v1/auth/guest-init | jq -r .access_token)

# 列出集合 → 取每本的 storageRef → 直接下载
curl -s -H "Authorization: Bearer $TOKEN" \
  https://api.linguoland.com/api/v1/catalog/collections/13 \
| jq -r '.items[] | [.title, .storageRef] | @tsv'
```

`storageRef` 全部指向 `linguo-land.oss-cn-hangzhou.aliyuncs.com`，无签名、无过期、无 Referer 校验。

### 5.2 如果要写 Loon 插件（只解 UI，不解能力）

```ini
[mitm]
hostname = api.linguoland.com

[rewrite_local]
^https:\/\/api\.linguoland\.com\/api\/v1\/auth\/quota-status url script-response-body linguoland_quota.js
```

```js
// linguoland_quota.js —— 仅让"额度用尽"弹窗消失；AI 调用仍会被服务端拒
let o = JSON.parse($response.body);
o.tier = "LIFETIME";                      // 客户端据此隐藏购买入口（枚举值取自串池 GUEST/…，需实机抓包确认全量枚举）
if (o.membership) { o.membership.isLifetime = true; o.membership.daysLeft = 36500; }
const cap = { ENRICH: 9999, TRANSLATE: 9999, CHAT: 9999 };
for (const k in (o.quotas || {})) {
  const c = cap[k] || 9999;
  o.quotas[k].limit = c; o.quotas[k].remaining = c; o.quotas[k].used = 0;
}
if (o.cost) { o.cost.remainingCents = 999999; o.cost.usedCents = 0; }
$done({ body: JSON.stringify(o) });
```

### 5.3 卡点

1. **AI 请求由服务端计量**：`/api/v1/ai/chat-stream` 等流式接口会用 token 反查账号 tier 与 credits 余额，402/403 由服务端决定，客户端 JSON 改不动。
2. **OTA 热更**：`EXUpdatesCheckOnLaunch=ALWAYS`，客户端判定逻辑随时可被替换，任何"改包内常量"的做法寿命很短。
3. 订阅路由（`/v1/subscriptions/*`）在本 host 未挂载（404），实际网关前缀需登录态抓包确认；但它们不影响结论——权益已由 `quota-status` 直接给出。
