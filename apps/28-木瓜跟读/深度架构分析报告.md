# 深度架构分析报告：28-木瓜跟读

本报告基于脱壳 Mach-O 二进制符号提取、编译期源文件拓扑（`#file`）、URL 与域名契约提取及 REA 6.8.0 Application Graph 静态反编译事实生成，覆盖应用 `cn.luffy.echo`（v1.0.1，最低支持 iOS 17.6）。

## 一、技术栈与播放内核

- **客户端架构**：纯原生 Swift / UIKit + SwiftUI 混编体系。主二进制达到 31.86 MB，依赖 18 个动态库 Framework（包含 `Alamofire`、`Moya`、`FMDB`、`Kingfisher`、`SnapKit`、`ESTabBarController_swift`、`MJRefresh`、`KakaJSON`、`SSZipArchive`）。
- **播放内核**：未引入 mpv 或 ffmpeg，基于苹果原生 `AVFoundation` 架构（`AVPlayer`、`AVPlayerItem`、`AVPlayerLayer`、`AVAudioPlayer`、`AVAudioEngine`）。自定义控制器 `PlayerViewController` 承载视频渲染，由 `AudioProcessor` 进行底层音频流调度。
- **内嵌模型与推理引擎**：集成了极其重度的端侧机器学习与模型推理矩阵：
  - **WhisperKit（Argmax CoreML）**：深度内嵌 `WhisperKit`、`WhisperKitConfig`、`WhisperMLModel`、`WhisperManager`、`WhisperTokenizerWrapper`，在苹果端侧 Apple Silicon NPU 上直接离线运行 Whisper 语音识别。
  - **分词与模型管理**：内置 `WordpieceTokenizer`、`WordPieceDecoder`，并包含 `LanguageModelConfigurationFromHub`、`LanguageModelManager`。
  - **TensorFlow Lite 与底层算子**：静态源码中编译打包了 TensorFlow Lite 内核（`audio_spectrogram.c`、`tflite_executable.c`）与 Google Babelfish / NLP 词典算子（`nlp/wordlens/nmt_decoder`、`absl`）。
  - **系统 ASR 兜底**：同时保留苹果系统级语音识别组件（`SFSpeechRecognizer`、`SFSpeechAudioBufferRecognitionRequest`、`SFSpeechLanguageModel`）。

## 二、模块分层

根据 583 个原生类与 2448 条编译期源码路径，应用结构清晰划分为以下四大工程层次：

1. **表现层（View & ViewControllers）**：
   - 播放与字幕交互：`PlayerViewController`、`SubtitleCardView`、`SubtitleCell`、`SubtitleCardCell`、`EditSubtitleViewController`。
   - 列表与分类展示：`VideoListViewController`、`NetworkVideoListViewController`、`HomeVideoCell`、`VideoItemCell`、`VideoListCell`。
   - 词汇与闪卡交互：`FlashCardViewController`、`FlashCardHomeViewController`、`FlashCardStatisticsViewController`、`WordBookListViewController`、`WordCardView`、`BookCell`、`CelebrationCardView`、`HeatmapCardView`、`LearningStatsCardView`、`RichWordPopupView`、`WordPopupView`。
2. **端侧 AI 与音频流水线层（AI & Audio Pipeline）**：
   - 模型管理与 ASR 调度：`WhisperManager`、`WhisperKit`、`WhisperKitConfig`、`LanguageModelManager`。
   - 语音切片与特征提取：`VADAudioChunker`（VAD 语音活动检测分块）、`AudioStreamTranscriber`、`AudioProcessor`、`AudioUtils`、`AudioEncoder`、`AudioEncoderInput`、`AudioEncoderOutput`。
   - 录音控制：`RecordControlButton`、`AudioSettingsView`。
3. **数据持久化与素材库层（Persistence & Storage）**：
   - 数据库引擎：`DatabaseManager`（基于 `FMDB.framework` / SQLite3 深度封装本地数据）。
   - 文件与解压：`SSZipArchive`（用于离线资源包解压缩）、`CategoryModel`。
4. **网络与基础设施层（Network & Infrastructure）**：
   - 网络基础设施：基于 `Moya.framework` 与 `Alamofire.framework` 封装的请求层；`KakaJSON` 负责模型序列化；`Kingfisher` 负责封面图异步加载。

## 三、能力模块

- **影子跟读（Shadowing）与录音**：
  - 界面提供 `RecordControlButton`，由 `AudioProcessor` 与 `AudioSettingsView` 协同完成用户跟读录音的拾取，支持麦克风音量与音频设备参数调整。
- **A-B 复读与句子跳转**：
  - 在 `PlayerViewController` 中将音视频播放时间轴与 `SubtitleCardView` 联动，支持点击字幕条目即时 seek 到指定 A-B 区间，实现单句无限重复回放。
- **字幕管理与实时编辑**：
  - 具备强大的双向字幕处理能力：不仅支持常规展示（`SubtitleCell`、`SubtitleCardCell`），还特设独立控制器 `EditSubtitleViewController`，允许用户在端侧直接校对、拆分和修正字幕时间轴与文本。
- **抽认卡（FlashCard）生词复习引擎**：
  - 拥有极为完备的 SRS 生词记忆闭环：包含书籍词库（`WordBookListViewController`、`BookCell`）、翻卡训练（`FlashCardViewController`、`WordCardView`）、学习热力图打卡（`HeatmapCardView`）及成果结算（`CelebrationCardView`、`LearningStatsCardView`）。
- **本地素材库管理**：
  - `VideoListViewController` 配合 `DatabaseManager` 对本地导入与已缓存视频进行结构化管理，支持多维度分类（`CategoryModel`）。
- **端侧 AI 能力**：
  - 支持全离线本地大模型推理。当导入外部视频时，应用启动 `VADAudioChunker` 切分语音帧，通过 `AudioEncoder` 提取声学特征，送入 `WhisperKit` 完成本地精准转录，再通过 `WordpieceTokenizer` 逆向解码输出结构化字幕。

## 四、网络与 API 契约

- **自有域名与接口**：
  - 提取结果中仅命中用于开发测试的 `postman-echo.com`。
  - **完全无自建后端业务 REST API 接口**。
- **服务契约本质**：
  - 木瓜跟读是一套高度纯粹的 **Local-First（本地单机闭环）** 架构。
  - 视频解码、WhisperKit CoreML 离线推理、VAD 语音切片、字幕编辑修正、生词闪卡记忆数据库（FMDB/SQLite）均 100% 在 iOS 设备本地完成计算与持久化，不依赖云端账户或私有服务集群。

## 五、对自研的参考价值

1. **工业级 WhisperKit 端侧离线 ASR 落地模版**：完整跑通了 `VADAudioChunker`（端侧切片） -> `AudioEncoder` -> `WhisperManager`（CoreML 驱动 NPU） -> `WordpieceTokenizer`（分词还原）的本地视频字幕生成全链路，是自研端侧离线跟读产品的极佳代码范本。
2. **“播放器-字幕编辑-闪卡生词库”业务闭环设计**：将媒体播放（`PlayerViewController`）、字幕卡片流（`SubtitleCardView`）、字幕即时校订（`EditSubtitleViewController`）以及后续的生词复习卡片（`FlashCardViewController`）深度贯通，学习闭环设计极具参考价值。
3. **高稳定性的原生基础架构**：采用 SnapKit + Moya + Alamofire + FMDB + KakaJSON 的工程架构，充分展示了如何用成熟的 iOS 工业级原生轮子搭建高性能、无后端维护负担的单机工具型应用。
