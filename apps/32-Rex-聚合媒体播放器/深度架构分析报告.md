# 32-Rex 深度架构分析报告

## 一、技术栈与播放内核

- **基础规格**：Bundle ID 为 `tv.rexnow.app`，版本 `1.0.2`，最低系统 iOS `17.0`。主二进制 `85.75 MB`，内含 24 个独立动态库。
- **技术栈**：Swift 与 C/C++ 混编；引入 `onnxruntime.framework` 作为端侧 AI 运行时；集成全套音视频解码与排版库。
- **动态库矩阵（24 个）**：FFmpeg 家族（`Libavcodec` 等 7 库）、AV1 解码 `libdav1d`、色彩渲染 `libplacebo` / `libdovi`、字幕排版 `libass` 等、协议库 `AMSMB2`、AI 运行时 `onnxruntime`。
- **双播放内核与 Metal 渲染管线**：
  - **双播放内核**：基于 KSPlayer 深度定制提供 `KSVideoPlayerView`；集成原生 `AVPlayer` 与 `AVSampleBufferRenderSynchronizer`。
  - **硬件加速渲染**：依托 Metal 着色器（`MetalPlayView`、`MetalSubtitleView`），支持 HDR Vivid 与杜比视界（`HDRVividRenderer`、`DoviThumbnailRenderer`）。
  - **音频管线**：基于 `AVAudioEngine` 封装 `AudioEngineDynamicsPlayer`。

## 二、模块分层

原生类共 1771 个，归纳为六大核心层级：

1. **表现层（UI & Shell）**：卡片看板与媒体列表，如 `AdaptiveCardBackdropView`、`BoardCardStackView`、`MediaListViewController`。
2. **播放与渲染层（Playback Engine）**：解码调度与 GPU 渲染，如 `FFmpegDecode`、`MetalRender`、`KSPlayerRenderingContainerView`。
3. **协议接入与聚合层（Multi-Protocol Storage & Drives）**：
   - 局域网协议：`SMBDriveFileProvider`（`AMSMB2`）、`RexSMBIOContext`、`WebDAVDriveFileProvider`。
   - 媒体服务器：`PlexLibraryLoginCoordinator`、`DrivembyDAVClient`（Emby/Jellyfin）。
   - 网盘存储：`CloudAccessHTTP`、`DriveFileBrowserViewController`。
4. **媒体库管理与刮削引擎（Scraping & Metadata Hub）**：元数据识别与海报墙，如 `DriveScrapeCoordinator`、`DriveMediaRecognitionSession`、`BDMVMetadataStore`。
5. **字幕、弹幕与本地 AI 推理层**：
   - 字幕与投屏：`AssImageRenderer`、`AssrtSubtitleDataSource`、`AirPlaySubtitleServer`、`OpenAICompatibleSubtitleTranslator`。
   - 弹幕：`PlaybackDanmuTimelineController`、`PlayerDanmuOverlayView`。
   - 本地 ASR：`PartitionOnnxFormatModel`、`AudioSubtitleRecognitionModelStore`（内置 Sherpa-ONNX）。
6. **通行密钥与安全层（Auth & Gate）**：Passkeys 认证，如 `ASAuthorizationPlatformPublicKeyCredentialAssertion`、`CloudAppAttest`。

## 三、能力模块

- **视频导入与解析**：支持全协议导入。支持 SMB、WebDAV、Plex、Emby、Jellyfin 与网盘；支持 ISO / BDMV 原盘解析（`BDMVMetadataStore`）；支持本地沙盒与网络直链。
- **字幕与翻译**：内嵌完整 `libass` 渲染栈（`AssImageRenderer`、`MetalSubtitleView`），支持特效字幕；内置射手网与 OpenSubtitles 在线搜索；通过 `AirPlaySubtitleServer` 解决投屏外挂字幕同传；集成 `OpenAICompatibleSubtitleTranslator` 接入大模型翻译。
- **跟读与语音识别（AI）**：借助 ONNX Runtime 运行离线语音模型，由 `RexSpeechRecognitionProvider` 本地提取音轨生成字幕与对齐时间轴。
- **云盘/协议接入**：
  - **SMB**：基于 `AMSMB2` 封装 `RexSMBIOContext` 实现低延迟流缓冲。
  - **WebDAV**：`WebDAVDriveFileProvider` 支持自定义 Header 与断点续传。
  - **Plex / Emby**：原生 Token 握手、媒体库结构同步与进度回传。
  - **115 / 网盘**：支持扫码授权（`qrcodeapi.115.com`）与直链解析。
- **媒体库管理与弹幕**：`DriveScrapeCoordinator` 自动化解析文件名并关联 TMDB/豆瓣生成海报墙；`PlaybackDanmuTimelineController` 接入弹弹play 并在 Metal 视图高帧率渲染弹幕。

## 四、网络与 API 契约

- **自有域名与核心接口（12 个自有域名）**：
  - `api.rexnow.tv`：元数据与播放接口（`https://api.rexnow.tv/api/metadata`、`/playback/metadata`）。
  - `auth.rexnow.tv`：Passkeys 服务（`https://auth.rexnow.tv/v1/native/passkeys/login/options`、`https://auth.rexnow.tv/v1/account`）。
  - `feedback.rexnow.tv`：会话遥测（`https://feedback.rexnow.tv/api/rex/session`）。
  - `assets.rexnow.tv`：动态脚本分发（`https://assets.rexnow.tv/scripts/`）。
  - 环境域名：`rexnow.tv`、`tv.rexnow.app`、`tv.rexnow.cloud`、`tv.rexnow.license.dev` 等。
- **核心依赖接口**：
  - **影视元数据**：TMDB (`api.themoviedb.org`)、Trakt (`api.trakt.tv`)、豆瓣 (`m.douban.com`)。
  - **字幕与弹幕**：射手网 (`api.assrt.net`)、OpenSubtitles (`api.opensubtitles.com`)、弹弹play (`api.dandanplay.net`)。
  - **网盘授权**：115 (`passportapi.115.com`、`qrcodeapi.115.com`)。
  - **AI 翻译端点**：OpenAI (`api.openai.com`)、DeepSeek (`api.deepseek.com`) 等。

## 五、对自研的参考价值

1. **统一存储驱动抽象架构（DriveFileProvider）**：Rex 将 SMB、WebDAV、Plex、Emby 与网盘统一抽象为 `DriveFileProvider` 与 `DriveEntryRecord`，刮削引擎（`DriveScrapeCoordinator`）与播放器完全解耦于底层物理存储，大幅降低多协议扩展成本。
2. **双内核与 Metal 深度定制管线**：兼具 `AVPlayer` 的低功耗与 FFmpeg / KSPlayer 的全格式解码能力（AV1、Dolby Vision、BDMV）；通过 Metal 着色器（`MetalPlayView`、`MetalSubtitleView`）将 libass 字幕与弹幕直接渲染在 GPU 纹理上，避免主线程掉帧。
3. **AirPlay 外挂字幕同步服务（AirPlaySubtitleServer）**：针对 iOS 原生 AirPlay 无法推流外挂字幕的系统痛点，Rex 在本地启动轻量 HTTP 服务动态封装推流外挂字幕，为自研投屏提供了成熟方案。
4. **混合 ASR 与开放 AI 翻译生态**：端侧基于 ONNX Runtime 内置 Sherpa-ASR 离线语音识别，支持设备端提取音轨自制字幕；同时兼容 OpenAI 协议对接各类云端大模型做双语翻译，兼顾基础离线体验与高级智能增强。
