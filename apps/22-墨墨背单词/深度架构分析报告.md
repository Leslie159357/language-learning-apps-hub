# 22-墨墨背单词 深度架构分析报告

## 1. 技术栈判定
- **架构范式**：纯原生 Swift 与 Objective-C 深度混编架构，属于现代重型企业级工程。全面采用响应式编程，集成全套 RxSwift 矩阵（`RxSwift`, `RxCocoa`, `RxRelay`, `RxDataSources`），并通过 `Swinject.framework` 实施依赖注入。
- **播放内核与通信**：多套多媒体引擎复合驱动。音频解码与变速变调使用腾讯内核 `TXFFmpeg.framework` 与 `TXSoundTouch.framework`；同时内嵌声网音视频通信套件（`AgoraRtcKit.framework`, `Agoraffmpeg.framework`, `AgoraAiNoiseSuppressionExtension` 等），配合系统 `AVAudioEngine` 提供高保真发音与连麦。
- **依赖 SDK 与动态库**：包内含 52 个动态框架。数据层集成微信 `WCDB.framework` 与加密库 `sqlcipher.framework`；网络层使用 `Moya.framework` 与 `SwiftProtobuf.framework`（Protobuf 序列化）；监控集成 `Sentry.framework`。
- **规模**：主二进制 94.18 MB，包内文件 1211 个；原生类 2686 个，应用源文件 1110 条，内嵌库源文件 205 条。

## 2. 模块分层
- **导航层**：解耦页面路由。代表类：`ASSNetworkCoordinator`（基于 Coordinator 模式的流转协调器）、`AboutSubTableVC`、`DefaultFakeNavigationBar`。
- **播放引擎层**：发音点播与连麦引擎。代表类：`AudioDecoderController`、`AudioEngineHelper`、`MMCDNLivePlayer`（自研 CDN 播放器）、`RtcCDNLivePlayer`（RTC 连麦播放器）、`BottomPlayerView`。
- **业务服务层**：承载记忆算法与外围服务。代表类：`AdvanceReview`（艾宾浩斯复习调度核心）、`ApiUserVocabularyService`（词汇服务）、`ExportPDFService`（PDF 导出服务）、`AudioDownloadManager`、`ABTestService`。
- **数据层**：依托 WCDB 构建的高性能持久化及统计模型。代表类：`ChartReviewAndNewData`（复习图表模型）、`ChartReviewAndNewDataIds`、`ChallengePhraseModel`、`BookPrediction`（词书预测模型）。
- **UI 层**：承载背词与图表展现。代表类：`CalendarViewController`（复习日程表）、`ChatMessageView`（语伴私信）、`PhraseAnnotationButton`（词组交互高亮）、`FeedbackSpeechUpdateView`。

## 3. 能力模块
- **播放与多音轨**：通过 `TXFFmpeg` 与 `AudioDecoderController` 实现单词发音的高速缓存与播放；利用 `TXSoundTouch` 进行发音语速微调；借助 Agora RTC 音频管道实现多人自习室连麦。
- **字幕与词汇渲染**：基于 `TTTAttributedLabel` 与 `PhraseAnnotationButton`，在例句与释义中实现词根词缀拆解、语法高亮与词组点击取词。
- **词汇与记忆算法**：核心护城河。基于 `AdvanceReview` 模块动态计算单词遗忘临界值，由 `BookPrediction` 计算学习周期，由 `ChartReviewAndNewData` 绘制记忆曲线图表。
- **跟读录音与评分**：集成 `FeedbackSpeechUpdateView`、`ClickRecordButtonModel` 与原生 `AVAudioRecorder`，提供用户跟读采样与发音对比。
- **导入导出**：内置 `ExportPDFService`，支持将用户生词本排版后直接导出矢量 PDF 文件用于脱机打印；支持词书云端同步。

## 4. 网络与 API 契约
构建了完整的自研微服务接口矩阵，核心自有域名为 `maimemo.com`：
- `https://apis.maimemo.com/study/api/v1/sync/checkpoints`：核心学习状态同步端点，处理单词学习进度、遗忘状态与断点的全量增量双向同步。
- `https://apis.maimemo.com/study-partner/sessions/`：学习搭子匹配与自习室会话建立。
- `https://voctest.maimemo.com/voc_test/app`：动态词汇量自适应测验接口。
- `https://maimemo.com/pages/book-predict`：词书抗遗忘学习规划与周期预测计算。
- `https://apis.maimemo.com/study-partner/learners/pricing`：连麦增值与付费权益配置。

## 5. 源文件拓扑
- **主工程结构**：源码编译路径聚合于 `/0/maimemo/memo/momo-ios/build/momo-ios_sec/momo_ios/`：
  - `Entry/`：启动控制与系统委托（`LaunchView.swift`, `AppDelegate+Addition.swift`）。
  - `Cache/`：WCDB 本地缓存调度（`CacheManager.swift`）。
  - `PhraseNote/`：词组标注与曝光追踪（`PhraseAnnotationButton.swift`）。
  - `UserLevel/`：用户等级与激励（`LevelLoader.swift`）。
- **三方与内嵌库区隔**：源文件列表中包含较多底层静态库，如 `/../third_party/opus`（Opus 音频编码器）、`/../third_party/boringssl`（BoringSSL）、`/../sdk/live`（腾讯云推流底层）。主工程在 Swift 层通过封装桥接（如 `HostMomoCmpBridge.swift`）与底层保持解耦。

## 6. 对自研的参考价值
1. **数据存储选用 WCDB**：面对海量复习记录高频读写、多表关联统计场景，采用 `WCDB` + `SQLCipher` 代替 CoreData，保证并发性能与数据加密。
2. **Rx 响应式规范**：通过 RxSwift 构建单向数据流与 Coordinator 导航体系，有效掌控背词时的复杂分支状态机。
3. **衍生功能提留存**：开发 `ExportPDFService` 导出实体词书打印版，切中脱离屏幕复习需求，增强差异化竞争力。
