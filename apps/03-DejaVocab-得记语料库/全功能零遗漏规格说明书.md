# DejaVocab (v2.3.6 最新版) 全功能零遗漏深度规格白皮书

> 依据：脱壳 Mach-O 二进制符号提取、REA 6.8.0 Application Graph 全量反编译证据链。
> 提取到 **1,034 个原生组件**，无一遗漏全景归类。

---

## 一、 个人语料库引擎 (257 个核心组件)

### 1. 语料提取核心
- **CorpusContextExtractor**：生词上下文提取器。当用户在看剧或阅读中收藏生词时，**自动抓取生词所在句、前一句、后一句作为完整语境**，并自动切取 3 秒原声音频。
- **DiffableDecoration+HTML**：注入 Web 容器的高性能荧光笔高亮系统，零延迟标记已学、未学单词。
- **PublicationMediaLoader** / **AudioNavigator**：基于 Readium 架构的多媒体有声同步导航器。

---

## 二、 App 原生内置 Anki 引擎 (35 个核心组件)

### 1. Anki 状态机与算法
- **AnkiService** / **AnkiViewModel**：完整实现 Anki 调度逻辑与 FSRS 算法。
- **AnkiCardState**：严格维护 `new` / `learning` / `review` / `relearning` 四态。
- **AnkiDifficultyBadge**：支持 `Again` / `Hard` / `Good` / `Easy` 四档评分与下一次复习间隔换算。

### 2. 卡片交互与伴读播放
- **AnkiCardAudioPlayer**：原声伴读播放器，翻卡瞬间调用原声音频原汁原味回放。
- **AnkiCardView** / **AnkiCardDetailView**：卡片正反面翻转渲染。
- **AnkiPhraseTypingMode**：拼写练习模式，支持逐字打字纠错。
- **AnkiMasteryDashboardView**：记忆掌握度看板与 GitHub 风格学习热力图。
