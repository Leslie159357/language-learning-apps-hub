## 4. 可解锁分级

### 结论：**B 级（偏 B+，客户端可改面最大，但仍受 SOE 额度与内容下发限制）**

**可解证据**
1. 会员态是**用户对象里的字段**，客户端 getter `isPaidMember`/`isMember` 是纯本地读取；`_showMembershipOnlyDialog`、`_checkMemberForTranslate`、`_ensureRecognitionMember` 都是**客户端主动判断**后才拦。
2. 存在 `读取本地有效购买` + `purchased_product_id_data` / `purchased_product_id_net`：购买态在本地留有副本，说明启动时先信本地、再打网络（有离线宽限窗口）。
3. 协议层无请求签名（只有 `Authorization`），Loon 可对 `/api/auth/user` 做 JSON 字段改写。
4. Pro 能力主体在本机：mpv/ffmpeg/libass 全在包内，OCR/ASR 模型 79 MB 随包（`yolo8.onnx`+PaddleOCR+sherpa），**字幕识别/翻译/解析可以纯离线完成**——只要客户端开关放开，功能真能跑。

**限制项（为什么不是 A）**
1. 课程视频与课文元数据从 `video-app-api.chengmu.cc` / `static-video.chengmu.cc` 下发（`/api/media/episode`、`/api/home/section/media`），**没有内容库就没有可跟读的素材**，这部分改写造不出来。
2. 跟读评测走 `/api/soe/v2/assess`（服务端评测）+ `/api/soe/v2/quota` 计次，`会员不限次` 是服务端记账；本地改 `isMember` 只让 UI 不再拦，请求到了服务端仍按真实额度回限额（`_isSoeQuotaLimitResponse` 已内置处理）。
3. 收据校验 `/api/pay/iosPayVerify` 是解锁的权威路径，`/api/pay/getPurchased` 每次冷启会拉真实已购列表 —— 只改本地会在下次拉取时被覆盖（故需持续 hook getter，而非一次性写键）。

## 5. 务实落点

### 5.1 Loon 落点（本包最有希望的一个）
1. **`video-app-api.chengmu.cc` + `/api/auth/user`**：响应里把 `isMember`/`isPaidMember` → true、`isTrialMember` → false、`memberType` → 年/永久枚举、`endTime` → 远期、`member_expired` → false，并同步 `memberLabel`/`memberName`（UI 会显示"正式会员"）。
   - 建议用 `url-regex` 精确锚定 `^https://video-app-api\.chengmu\.cc/api/auth/user`，`json-body` 改写，避免污染 `/api/auth/updateUser`。
2. **`/api/pay/getPurchased`**：填入 `y_member_forever_s`，配合上面让"恢复购买"路径也自洽（否则会被本地 `purchased_product_id_net` 比对打回）。
3. **`/api/soe/v2/quota`**：把额度数字改大 —— 但 `/api/soe/v2/assess` 仍由服务端扣真实次数，**只改展示**。
4. 注意：Flutter 的 `dart:io HttpClient` 不走 NSURLSession，但 Loon 是 **TUN 层 + 根证书 MITM**，仍能拦（除非有 pinning；包内仅见 `registerBadCertificateCallback`/`SecurityContext` 通用符号，未见 pinning 证书哈希，按"无 pinning"处理但需实测）。

### 5.2 本地补丁落点
- 首选 **hook 用户模型 getter**：`isPaidMember` / `isMember` / `isTrialMember` 恒真（Dart 层需改 AOT 或用 Frida 拦 `User.fromJson`）。
- 次选：改 SharedPreferences `purchased_product_id_data` / `..._net` 塞入 `y_member_forever_s`（`读取本地有效购买` 路径直接吃这个键）。
- 更彻底：patch `_showMembershipOnlyDialog` / `_checkMemberForTranslate` / `_ensureRecognitionMember` 的调用点，让会员门不触发。

### 5.3 真正卡在服务端的（直说）
- **内容库**：`/api/media/episode`、`/api/home/section/media` 与 `static-video.chengmu.cc` 的视频文件 —— 没下发就没有素材。
- **跟读评测（SOE）真实计次**：`/api/soe/v2/assess` + `/api/soe/v2/quota` 服务端记账；"会员不限次"对服务端才是真的不限次。
- **积分（次数包）**：`/api/pay/creditInfo` 服务端余额。
- 结论：**字幕识别/翻译/解析这类纯本地算力功能可以真解开（B+）；跟读评测次数与课程内容不行。**
