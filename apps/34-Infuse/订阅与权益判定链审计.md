## 1. 播放内核与底层渲染架构

### 1.1 核心播放引擎与解码管线
Infuse 采用了基于 **深度定制 FFmpeg** 的独立全自研多媒体管线，二进制中未发现 mpv 或 VLC 代码痕迹。整体播放框架采用分层架构：
- **容器解复用与核心解码**：集成 FFmpeg 动态库全集（`libavcodec.framework`, `libavformat.framework`, `libavfilter.framework`, `libavdevice.framework`, `libavutil.framework`, `libswresample.framework`, `libswscale.framework`）。
- **专业媒体与光盘镜像**：
  - `libbluray.framework`：提供完整的 BDMV 原盘导航、BD-J 交互支持与 ISO 文件解析。
  - `libudfread.framework`：提供 UDF（Universal Disk Format）文件系统底层驱动，支持免解压直读 DVD / Blu-ray ISO。
  - `libdav1d.framework`：高性能 AV1 软解加速。

### 1.2 硬解与 HDR / 视频渲染链路
- **硬件解码加速**：通过 `FCMPEG4HWDecodingEngine` 封装 Apple 原生 `VideoToolbox.framework`，支持 H.264、HEVC (H.265)、ProRes 硬件解码加速。
- **Metal 渲染管线**：视频后处理与最终渲染完全构建于 Apple Metal 之上：
  - 视图呈现：`FCAVPlayerDrawableView`, `CustomAVPlayerDrawableView`, `CAMetalLayer`。
  - 纹理与画质增强：`FCMetalTextureSmoother`, `FCMetalVideoPicturePreprocessor`, `FCCachingMetalFrameTexturesBuffer`。
  - HDR 与杜比视界支持：支持 HDR10、HLG 以及 Dolby Vision（Profile 5, Profile 8.1/8.4 单层及 Profile 7 双层色调映射至 HDR10 或 SDR）。
- **AVPlayer 回退机制**：包含 `FCAVPlayerController` 与 `AVPlayerViewController_WithDismissalHandler`，针对原生 HLS 流、AirPlay 投屏及特定系统受保护流做原生回退。

### 1.3 多声道音频处理
- 音频渲染采用底层 CoreAudio 封装：`FCAQRenderer` (AudioQueue) 与 `FCAURenderer` (AudioUnit)。
- 支持 Dolby Atmos（杜比全景声，含 E-AC3 JOC 与 TrueHD 核心）、DTS-HD Master Audio、DTS:X、FLAC 24bit/192kHz 无损多声道直通（Passthrough）与空间音频（Spatial Audio）渲染。

### 1.4 字幕渲染引擎
- **未集成 libass**：Infuse 自行研发了基于 Metal 纹理图层的硬件渲染字幕管线：`FCMetalSubtitleRenderer`, `FCMetalSubtitleRendererFactory`。
- 文本简繁转换：集成 `OpenCC.framework`（开放中文转换开源库）。

### 1.5 扩展与技术栈
- **语言与架构**：Swift 5.9+ 与 Objective-C 混编架构。
- **框架生态**：
  - 依赖注入：`Swinject.framework`
  - 响应式编程：`RxSwift.framework`, `RxCocoa.framework`, `RxRelay.framework`, `RxDataSources.framework`
  - 遥测与埋点：`FirebaseCore`, `FirebaseCrashlytics`, `FirebaseRemoteConfig`, `FirebaseSessions`
  - 投屏扩展：`GoogleCast.framework` (Chromecast)
  - 密码学与安全：`JOSESwift.framework` (JWS/JWT 验证), `UICKeyChainStore.framework`
  - 缓存与图片：`Kingfisher.framework`

### 2.2 Pro 判定核心类、类型与方法
1. **StoreKit 2 核心服务**：
   - 类名：`_TtC6infuse31InAppPurchaseServiceFreemiumSK2` (继承自 `FCInAppPurchaseServiceBase`)
   - 内部组件：
     - `_TtCC6infuse31InAppPurchaseServiceFreemiumSK212Transactions`：交易生命周期管理。
     - `_TtCC6infuse31InAppPurchaseServiceFreemiumSK27Storage`：交易收据本地落盘。
     - `_TtCC6infuse31InAppPurchaseServiceFreemiumSK28Products`：SKProduct / Product 列表管理。
     - `_TtCC6infuse31InAppPurchaseServiceFreemiumSK219TransactionObserver`：StoreKit 2 交易更新监听器 (`Transaction.updates`)。
   - 关键判定方法：
     - `iapVersionStatus()`：计算当前版本 Pro 权限状态，返回 `FCIAPVersionStatus` 枚举。
     - `restoreCompletedTransactions()`：恢复交易。
     - `updateReceipt()`：刷新并校验 StoreKit 2 JWS 交易签名。
2. **企业版特权桩**：
   - 类名：`_TtC6infuse30InAppPurchaseServiceEnterprise`
   - 初始化即全功能放行（`Enterprise service init - all Pro features enabled`）。
3. **播放前置门禁策略**：
   - 类名：`FCInAppPlaybackStrategy`
   - 门禁判定项：
     - `iapFeatureTitleVideoFormats` / `iapFeatureDescriptionVideoFormats`（VC-1, HEVC 4K, BDMV 等受限封装与编码）
     - `iapFeatureTitleHDAudio` / `iapFeatureDescriptionHDAudio`（Dolby TrueHD, DTS-HD MA 等高清音频）
     - `iapFeatureTitleCloudStreaming`（云盘直链解析与在线播放）
     - `iapFeatureTitleSync`（iCloud / Trakt 库同步）
     - `iapFeatureTitleAirPlay`（全规格 AirPlay 音视频投屏）

### 2.3 本地缓存位置与持久化机制
- **App Group 跨应用共享容器**：
  - Group ID：`group.com.firecore.shared`
  - 配置文件路径：`Library/Preferences/com.firecore.sharedinfo.plist`
  - 核心字典键名：`ProStatusDict`
  - 服务实现：`FCIAPSharingStatusServiceImpl.m` (`-[FCIAPSharingStatusServiceImpl hasSharedProStatusFromNonSubscribingVersion]`, `-[FCIAPSharingStatusServiceImpl shareProStatus:]`)
  - 作用：在 Infuse 独立买断版（如 Infuse Pro 6/7）与免费订阅版（Infuse 8）之间共享购买状态。
- **Keychain 安全存储**：
  - 钥匙串服务标识：`com.firecore.infuse.receipts` 与 `com.firecore.infuse.shared_receipts`
  - 存储内容：由 `InAppPurchaseServiceFreemiumSK2.Storage.swift` 写入经过签名的 App Store Receipt 与 Transaction JWS。

### 2.4 服务端校验环节与网络接口
1. **Apple StoreKit 2 官方链路**：
   - 依赖本地 iOS 系统的 `storekitd` 守护进程与 Apple 服务器直接通信。
   - 验证方式：本地直接解包并校验 Apple Root CA 签发的 JWS（JSON Web Signature）有效性。
2. **Trakt.tv 跨平台 Pro 共享同步**：
   - 服务类：`TraktPurchaseSharingModel.swift`, `TraktPurchaseSharingModel+S3.swift`, `TraktPurchaseSharingModel+Trakt.swift`
   - 域名与接口：
     - 认证与账号绑定：`https://apiz.trakt.tv/oauth/token`, `https://apiz.trakt.tv/users/settings`
     - 同步存储接口：`https://apiz.trakt.tv/storage/`
     - 亚马逊 S3 远程加密备份：`s3(localFile:remoteFileKey:direction:)`, `upload(receipt:forAccounts:key:)` 走 `.amazonaws.com`
3. **第三方 Remote Config / Paywall**：
   - 集成 Adapty SDK：`https://api.adapty.io/api/v1`, `https://api-cn.adapty.io/api/v1`, `https://configs-cdn.adapty.io/api/v1`。

## 5. 可测性分级与静态审计结论

### 5.1 可测性分级：**S2** (混合验证与本地策略控制)

### 5.2 判定依据与审计证据
1. **客户端完全自治的编解码管线（非 S3）**：
   - 所有的 FFmpeg 解码器、VideoToolbox 硬解管线、Metal 渲染着色器均 100% 静态编译在客户端 App 二进制及动态 Framework 中。
   - 播放无需向 Firecore 云端申请解密密钥、播放许可证书或 CDM 解密令牌。因此排除 S3。
2. **多源状态机判定路径（满足 S2 特征）**：
   - Infuse 采用 StoreKit 2 原生系统判定，苹果的 JWS 验签由操作系统完成。
   - 但应用为了兼容历史版本和跨生态（如 Pro 6/7 买断老用户、Trakt 账号跨 Android/Mac/AppleTV 共享），设计了多条合法状态回退旁路：
     - **旁路 1**：`FCIAPSharingStatusServiceImpl` 读取 App Group 的 `com.firecore.sharedinfo.plist` 中的 `ProStatusDict`。
     - **旁路 2**：`TraktPurchaseSharingModel` 从 Trakt TV 同步收据记录。
     - **旁路 3**：`InAppPurchaseServiceEnterprise` 预留的企业全放行模式。
   - 测试人员可以通过注入 App Group 容器文件、配置 Xcode StoreKit 测试文件或模拟 Trakt API 响应，完成 free / trialing / paid / expired 全状态的状态机自动化回归测试。
