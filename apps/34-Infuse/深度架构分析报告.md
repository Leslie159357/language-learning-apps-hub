# Infuse 深度架构分析报告

## 1. 播放内核与渲染实现
Infuse 采用自主研发的工业级混合多媒体播放架构，以定制化 FFmpeg 为基础解复用与软解基石（包含 FCFFMPEGDemuxingStream、FCFFMPEGBitStreamFilter、FCFFMPEGAudioMixer、FCFFMPEGFilter 及 FCFFMPEGSubtitlesDecoder），并按需桥接系统原生 AVPlayer（FCAVPlayerController 与 AVDisplayLayerDecoder），统一受控于上层播放调度器（FCMPPlayer、FCMPTransmuxingPlayer、FCMediaPlayer、FCVideoPlayer）。
- **硬件解码与软解回退**：构建完整的 VideoToolbox 硬件解码流水线，由 FCVTHardwareDecoder、FCVTDecodingSession、FCHWDecodingEngine 驱动，并针对 H.264/HEVC 细化为 FCAvccHWDecodingEngine、FCH264HWDecodingEngine 与 FCHEVCDecodingEngine；当硬解受阻时平滑无缝回退至 FCSoftwareDecoder 与 FCSimpleStreamVideoDecoder。
- **HDR 与 Metal 渲染管线**：色彩映射层具备 DolbyVisionConfiguration 与 FCColorTransformationsHelper，渲染输出依托自研 Metal 渲染引擎 FCMetalImageRenderer、MetalAmbientRenderer、FCEnhancingMetalTexturesFilter 与 FCMetalShaderCache，支持自适应帧率刷新（RefreshRateHandler）。
- **音轨直通与多声道渲染**：音频链路集成 FCPassthroughSPDIFMuxer.m 实现硬件级 S/PDIF 压缩数字直通，并配备 FCPassthroughAudioDecoder 与 FCSoftwareAudioDecoder；音频输出采用分层渲染器 FCAudioPlayer.swift、FCSampleBufferAudioRenderer、FCAQRenderer（AudioQueue）与 FCAURenderer（AudioUnit）。
- **字幕解码与 GPU 渲染**：支持 FCASSSubtitlesDecoder、FCASSLogsParser 与 FCSSAParser，字幕字形通过 FCSubtitleAtlasPacker 进行纹理图集打包，交由 Metal 渲染管线 FCMetalSubtitleRenderer.m 与 FCSubtitleUnitsDrawBuffer 进行高效合成。

## 2. 模块分层结构
- **虚拟文件系统与媒体库层（VFS / Indexing / iCloudSync）**：高度抽象的资产管理中心。核心类包括 VFSManager、VFSBaseBrowser、VFSRemoteBrowser、VFSLibraryBrowser、FCVFSIndexState、FCMVFSIndexDAO、FCVFSSyncModel、FCVFSSyncSerializer、FCFolderFlagsManager 与 FCMetadataServiceTMDB。
- **播放内核层（CustomPlayer / Demuxing / Decoding / Rendering）**：承担流管道解析与多媒体解码。核心类包括 FCMediaPlayer、FCVideoPlayer、FCAudioPlayer、DemuxerFactory、FCFFMPEGDemuxingStream、FCHWDecodingEngine、FCMetalImageRenderer、FCMetalSubtitleRenderer 与 FCPassthroughSPDIFMuxer。
- **网络与共享服务层（Network / NetworkShares / Services / Discovery）**：承接局域网共享与云端存储协议。核心类包括 FCNQSMBConnectionManager、FCSLSMBConnectionManager、FCNQSMBInputStream、FCSLSMBInputStream、FCNQSMBDiscoveryService、FCSMBCompositeDiscoveryService、EmbyApi、EmbyBrowserDefault、VFSRemote+Emby 与 Cloud115AuthFlow。
- **UI 与交互控制层（GUI / Controllers / VideoController）**：用户交互与播放控制。核心类包括 FCItemsViewController_iOS、FCIosMacBaseControlPanelView、Playback.PlayerSetupper、Playback.PlayerDelegate、Playback.AudioEventsHandler、FCSubtitlesDownloadViewController、AddFilesShareDetailsExpandCell 与 AddPlexShareFlow。

## 3. 协议与云盘接入
- **局域网与流媒体协议**：SMB 协议采用独特的双协议栈架构，并行集成商业级 libnqsmb（iNQ_1.1.1_ios8，核心类 FCNQSMBConnection、FCNQSMBInputStream）与开源 Samba 实现（FCSLSMBConnection、FCSLSMBInputStream），由 FCSMBCompositeDiscoveryService 统一发现；全面支持 WebDAV（如 webdav.put.io、dav.real-debrid.com）、Emby/Jellyfin（EmbyApi、EmbyConnectLoginController）、Plex（AddPlexShareFlow、VFSPlexMetadataRequest、FCPlexCollectionsCache）及 SSH/SFTP（libssh.org、libssh2.org）。
- **云盘驱动接入**：覆盖 115网盘（Cloud115AuthFlow、Cloud115Share）、百度网盘（BaiduShare、pan.baidu.com/rest/2.0/xpan/）、阿里云盘（openapi.aliyundrive.com）、广雅云盘（openapi.guangyapan.com）、Google Drive（VFSGoogleDriveBrowser）、Dropbox（DropboxPathHelper）、OneDrive（graph.microsoft.com）、Yandex Disk（cloud-api.yandex.net）、MEGA（g.api.mega.co.nz）与 pCloud。
- **OAuth 鉴权域名与回调**：
  - 自有代理网关：https://app.firecore.com/115drive 与 com.firecore.cloud。
  - 115网盘：设备码端点 passportapi.115.com/open/authDeviceCode，令牌换取 passportapi.115.com/open/deviceCodeToToken。
  - Emby Connect：https://connect.emby.media/service/user/authenticate。
  - Plex：https://app.plex.tv/auth/#!?clientID=。

## 4. 网络与 API 契约
- **自有服务与云同步**：app.firecore.com 与 com.firecore.infuse.indexing.pro（支撑跨设备云端索引与状态同步）；商业化订阅基于 Adapty（api.adapty.io、configs-cdn-cn.adapty.io）。
- **影视元数据与打卡契约**：TMDB 原生 REST API（api.themoviedb.org 与 image.tmdb.org/t/p/）、TheIntroDB 片头跳过识别（api.theintrodb.org）、Trakt 深度同步契约（apiz.trakt.tv/scrobble/... 与 sync/watched/...）。
- **字幕服务契约**：OpenSubtitles 官方 v1 契约（api.opensubtitles.com/api/v1/subtitles、download 与 infos/languages）。

## 5. 对自研的参考价值
- **VFS 极度纯粹的虚拟化抽象**：所有协议（本地/SMB/NFS/WebDAV/网盘/媒体服务器）全部统一收归为 VFSItem、VFSBaseBrowser 与 VFSManager。上层媒体库、索引与 UI 面对的是单一虚拟文件系统树，与存储具体协议完全解耦。
- **流式 InputStream 管道化架构**：为每种存储介质实现专用 InputStream（如 FCNQSMBInputStream、EmbyInputStream），解复用器直接对输入流操作，网盘临时直链获取与续约集中在底层流管理中完成。
- **工业级自研播放架构标杆**：全链路自建 Demuxer、Decoder、Muxer、Renderer 四大组件，并在音频层支持 S/PDIF 压缩数字直通，在字幕层实现 Metal 纹理图集打包（FCSubtitleAtlasPacker），兼顾画质、音频还原度与内存效率。
