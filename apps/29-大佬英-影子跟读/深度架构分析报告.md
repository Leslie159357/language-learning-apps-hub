# 29-大佬英 深度架构分析报告

## 一、技术栈与播放内核

- **基础规格**：应用 Bundle ID 为 `com.dalaoE.dalaoE`，版本号 `1.0.8`，最低系统要求 iOS `18.0`。主二进制体积 `4.23 MB`，无独立动态库，包含扩展 `DalaoShareExtension`。
- **技术栈**：采用原生 Swift 与 UIKit / SwiftUI 混合架构，无内嵌 C/C++ 跨平台三方运行时。
- **播放与音视频内核**：依托苹果原生 `AVFoundation` 框架。视频回放由 `AVPlayer`、`AVPlayerItem`、`AVPlayerLayer` 提供；音频回放与混音使用 `AVAudioPlayer`、`AVAudioSession` 与 `AVAudioApplication`；底层音频缓冲及音轨解包依赖 `AVAudioPCMBuffer`、`AVAssetReader` 与 `AVAssetReaderTrackOutput`。

## 二、模块分层

根据符号全表与编译期源文件拓扑，应用呈现清晰的三层分工：

1. **表现层（UI / Views）**：以 SwiftUI 声明式组件为主，负责学习交互、创作者展示与导入。典型类包括 `ContentView`、`LearningView`、`CreatorsView`、`CreatorDetailView`、`CreatorSearchView`、`DalaoPaywallView`、`LocalVideoImportView`、`ImportView`。
2. **业务会话与领域层（Domain / Services）**：负责跟读生命周期管理、订阅状态与内容聚合。代表类包括 `LearningSession`、`LearningLibrary`、`CreatorService`、`CreatorCatalogLibrary`、`CreatorLibrary`、`PendingVideoImportLibrary`、`PendingVideoImportStore`、`DalaoSubscriptionStore`。
3. **媒体处理与引擎层（Media & Audio Engines）**：
   - **流媒体解析与加载**：`ClipboardVideoImport`、`SocialVideoWebResolver`、`SocialVideoStreamLoader`、`SocialVideoHTTPPolicy`、`BilibiliService`、`BilibiliAudioHTTPPolicy`。
   - **语音与音频处理**：`VoiceRecorder`、`SpeechAudioReader`、`WordSpeaker`、`AVAudioRecorder`、`AVSpeechSynthesizer`。
   - **自然语言与词典**：`DictionaryService`、`PhraseService`、`NLTokenizer`。

## 三、能力模块

- **视频导入与解析**：支持剪贴板链接自动提取（`SystemVideoLinkPasteboard`、`ClipboardVideoImport`）与本地导入（`LocalVideoImportView`）。外部短视频与长视频通过 `SocialVideoWebResolver` 内嵌 `WKWebView` 注入脚本抓取真实音视频流，配合 `SocialVideoHTTPPolicy` 与 `SocialVideoStreamLoader` 实现防盗链 Header 与分片载入；B 站视频由 `BilibiliService` 与 `BilibiliImportService.swift` 专职处理。
- **字幕与翻译**：内置 `CaptionSegmenter.swift` 实现字幕断句切片；通过 `BilibiliCaptionView` 渲染字幕；生词与短语通过系统 `NLTokenizer` 进行自然语言分词，调用 `DictionaryService` 与 `PhraseService` 呈现释义。
- **影子跟读**：`LearningSession` 维护跟读流转；`VoiceRecorder`（基于 `AVAudioRecorder`）录制用户发音；`WordSpeaker` 与 `SpeechAudioReader` 通过 `AVSpeechSynthesizer` 提供标准发音回放。
- **云盘/协议接入**：静态符号中未发现 WebDAV、SMB 或第三方网盘接入逻辑，纯基于本地文件与公网视频链接。
- **媒体库管理**：通过 `CreatorCatalogLibrary`、`CreatorLibrary`、`TrainingCategoryLibrary` 管理博主库与跟读分类，通过 `PendingVideoImportStore` 管理待导入任务队列。

## 四、网络与 API 契约

- **自有域名**：`0` 个。应用未部署任何私有后端服务，属于完全无服务器（Serverless）架构。
- **依赖域名与第三方接口**：
  - **Bilibili**：`api.bilibili.com`（导航接口 `/x/web-interface/nav`）、`player.bilibili.com`（内嵌播放器 `/player.html?bvid=`）、`bilivideo.com`、`hdslb.com`。
  - **YouTube**：`youtube.com`（播放数据接口 `/youtubei/v1/player`、频道浏览 `/youtubei/v1/browse`、RSS 订阅 `/feeds/videos.xml?channel_id=`、`iframe_api`）。
  - **抖音**：`open.douyin.com`（接口 `/api/douyin/v1/video/get_iframe_by_video?video_id=`、播放页 `/player/video?vid=`）、`douyin.com`、`iesdouyin.com`。
  - **小红书**：`sns-video-bd.xhscdn.com`、`xiaohongshu.com`。

## 五、对自研的参考价值

1. **纯客户端视频解析架构**：不依赖后端转码或代解析服务器，利用客户端 `WKWebView` 脚本注入（`WKUserScript`）动态提取第三方音视频地址，并由 `SocialVideoHTTPPolicy` 针对不同宿主定制 Referer 与 Header 规避反盗链，大幅降低自建服务器带宽与合规成本。
2. **极简免 ASR 跟读链路**：通过 `CaptionSegmenter` 结合已有时序字幕进行时间轴切割，录音直接走 `AVAudioRecorder`，单词发音与朗读调用系统原生 `AVSpeechSynthesizer`，生词切词利用 `NLTokenizer`，在零三方 API 成本下构建完整的影子跟读学习闭环。
