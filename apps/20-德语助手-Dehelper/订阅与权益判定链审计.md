## 1. 技术栈与架构

- **重型离词典 App**：包体 384 MB，绝大部分是离线词库与模型资源，不是代码。`Info.plist` 声明的 bundle 后缀是 `.ip`（iPad 优先布局），`UIDeviceFamily=[1,2]`，含 `NSSupportsLiveActivities`、`UIFileSharingEnabled`、`NSUbiquitousContainers`（iCloud `iCloud.com.eusoft.dehelper.Document`）。
- **随包动态框架（3 个，全是友盟）**：`UMCommon.framework`、`UMDevice.framework`、`UMAPM.framework`。
- **扩展 9 个（本批最多）**：
  `WidgetExtension_de`、`Today_de`、`TodayDailyWord_de`（今日/每日一词小组件）、`SafariExtension_de`（Safari 划词扩展）、`BroadcastUploadExtension_de`（录屏/广播上传）、`Lightpeek_de`（速览）、`EuDicCameraCaptureExtension_de`（相机取词）、`TranslationUIProvider_de`（系统翻译 UI）、`OfflineSpeechDownloader_de`。
- **Safari 扩展是独立前端工程**：包内 `manifest.json` + `chunk-*.js`（40+ 个）+ `serviceWorker.js` + `page-inject.js` + `marked.umd.js` + `polyfills.js`，是 MV3 形态的 Web 扩展（不是简单 WKWebView 注入）。
- **离线资源清单**（证明"查词不联网"）：
  - 词库索引 `F1.json`–`F5.json`、`M1.json`–`M5.json`
  - OpenCC 转换表 `HKVariants/STCharacters/TSCharacters/TWVariants…*.ocd2`
  - **CoreML 模型**：`DurationPredictor.mlmodelc`（TTS 时长预测）、`CoreMLImageExplain.plist` / `CoreMLImageSource_{de,es,fr}.plist`（拍照取词）
  - 样本内容 `Der Kleine Prinz.pdf`、`GlossaryTemplate.{txt,xlsx}`
- **架构判断**：查词/释义/发音（含离线 TTS）在端上完成；**AI 能力（AI 讲解、AI 对话、造句评测、AI 翻译引擎）全部 `/api/v5/ai/*` 服务端**；VIP 由「服务端 license 包 + 端上校验 + 缓存刷新日期」三段式决定。

## 2. 付费墙判定链

### 2.1 商品 ID

包内**无硬编码 SKU**（正则 `[\w-]+\.(vip|sub|iap|member)` 无有效命中）。商品来自服务端：

| 接口 | 证据 |
|---|---|
| `GET /api/v2/appsupport/IapProductList` | 与「听力」共用同一接口（两包同源），无参 GET 实测 500 |
| `GET /api/v2/appsupport/RecommendProducts` | 商品推荐位 |
| `GET /api/v5/ting/GetInAppPurchasePromotion?id=%@` | 促销位（同一套后端） |

购买链路是 **StoreKit 1（`SKPaymentQueue`）**：`EUPurchaseManager.paymentQueue:updatedTransactions:` @0x1008C597C、`buyProduct:` @0x1008C7A98、`paymentQueue:shouldAddStorePayment:forProduct:` @0x1008C6030（服务端商品信息通过 `getIAPInfo:success:failure:` @0x1004452B8 拉取，而不是本地 `SKProductsRequest` 直查）。

## 4. 可解锁面分级

| 级 | 内容 | 证据 | 结论 |
|---|---|---|---|
| **A** | 离线查词 / 离线词库 / 拍照取词 / 离线 TTS | `F1–F5.json`、`M1–M5.json`、`*.ocd2`、`DurationPredictor.mlmodelc`、`CoreMLImageExplain.plist` 全在包内；`/api/v2/dicts/*` 仅用于在线补充 | **这部分本来就不在付费墙内**，无需要解锁。也意味着"改本地开关"拿不到任何新能力。 |
| **B** | ① license 响应（`is_vip`/`vip_endtime`/`vip_islifetime`/`vip_timeframe`）② `AppTTSConfig` 的 `support_trans_vip`/`use_trans_vip` ③ `/api/v2/dictlib/listauth` 的库授权 | 字段名全部在串池；`license/*` 需登录态（401），响应体未取得 | ②是**最干净的一条**：布尔开关直接决定「翻译引擎」入口是否可选（`EUTransEngineSettingController.notSelectTransVip`）。改 true 即可让高端翻译引擎出现在选择列表 —— 但真正翻译仍走服务端（见 C）。①要过 `verifyLicensePackage:` 本地校验，伪造包需同时骗过校验行。 |
| **C** | AI 造句评测 / AI 对话 / AI 讲解 / AI 写作（`/api/v5/ai/*`） | `needVip`/`noBalance` 作为**服务端返回参数**出现在 `generateCardInfoStatusFromErrorState:needLogin:noBalance:needVip:` 等三个方法的签名里 | 服务端判定，重写无意义。 |
| **C** | 在线翻译引擎 / TTS 长文本 | `/api/v2/dictlib/transpreconfig`、`/api/v2/speech/PodcastTTSTask` | 服务端计量。 |

**总判定：付费墙主体 = AI/在线能力（C）；最有价值的 B 面是 `AppTTSConfig` 的 `support_trans_vip`/`use_trans_vip` 布尔开关（影响 UI 可选性，不影响服务端执行）。没有 A 级"本地开关即全解锁"。**

## 5. 务实落点

### 5.1 值得写的 Loon 规则

```ini
[mitm]
hostname = api.frdic.com

[rewrite_local]
# 翻译/TTS 能力配置：把 VIP 专属引擎开关打开（纯前端可选性）
^https:\/\/api\.frdic\.com\/api\/v2\/appsupport\/AppTTSConfig url script-response-body dehelper_tts.js
# license 查询：把 VIP 字段改成终身（仍会被 verifyLicensePackage 校验，多半只影响 UI）
^https:\/\/api\.frdic\.com\/api\/v2\/license\/(add|refresh|info) url script-response-body dehelper_license.js
```

```js
// dehelper_tts.js —— 只让"VIP 翻译引擎"出现在选项里
let o = JSON.parse($response.body);
const walk = (n) => {
  if (!n || typeof n !== 'object') return;
  if (Array.isArray(n)) return n.forEach(walk);
  for (const k of Object.keys(n)) {
    if (k === 'support_trans_vip' || k === 'use_trans_vip') n[k] = true;
    else walk(n[k]);
  }
};
walk(o);
$done({ body: JSON.stringify(o) });
```

```js
// dehelper_license.js —— 伪装终身会员（成功率取决于本地校验）
let o = JSON.parse($response.body);
const walk = (n) => {
  if (!n || typeof n !== 'object') return;
  if (Array.isArray(n)) return n.forEach(walk);
  for (const k of Object.keys(n)) {
    if (k === 'is_vip') n[k] = 1;
    else if (k === 'vip_islifetime') n[k] = true;
    else if (k === 'vip_endtime') n[k] = '2099-12-31 23:59:59';
    else if (k === 'vip_timeframe') n[k] = 0;
    else walk(n[k]);
  }
};
walk(o);
$done({ body: JSON.stringify(o) });
```

### 5.2 卡点

1. **`verifyLicensePackage:showSuccessMessage:showFailMessage:`** —— license 包有独立校验步骤（配合 `licenseVerifyLines` 校验行、`NOTIFICATION_LicensePackageVerifySuccess`）。只改 `is_vip` 字段而不动校验行，会在校验处失败；伪造整包需要逆向校验算法（本次未展开）。
2. **`/api/v2/license/*` 全部要登录态**（实测 401，`problem+json` + `traceId`），无凭证无法取得真实响应体，字段名来自串池而非实测样本。
3. **AI 能力**：`needVip`/`noBalance` 是服务端错误分类，端上无判定权。
4. 词库授权按 `productid` 逐库下发（`/api/v2/dictlib/listauth?…&productid=%d`），改 UI 不会让服务端放库。

### 5.3 本地补丁（非 Loon）

- hook `-[RegViewController licenseVerifyLines]`（0x10011E890）返回伪造校验行 / hook `EULicense` 的 Swift 判定；
- hook `-[EUPurchaseManager requestFinished:responseString:]`（0x1008CA3A8）在激活回包解析处直接注入 `is_vip=1`；
- 效果上限仍是 UI + 本地缓存；AI 与在线引擎不受影响。

### 5.4 一句话结论

这款 App 的"付费"主要卖**AI 与在线引擎**，离线词典本来就免费给你；Loon 改写能拿到的最好结果是"翻译引擎选项变多、会员标识变绿"，**拿不到 AI 额度**。
