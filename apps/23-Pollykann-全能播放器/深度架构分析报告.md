# 23-Pollykann-全能播放器 深度架构分析报告

## 1. 技术栈判定
- **架构范式**：纯原生 Swift 与 Objective-C 深度混编架构，采用模块化重型客户端设计，无跨平台框架。
- **播放内核与图形流水线**：搭载重型多媒体引擎 `Libmpv.framework`，配合全套开源渲染生态：集成 `Libass.framework`（ASS 特效字幕）、`Libplacebo.framework`（GPU 色彩管理与着色器渲染）、`Libdovi.framework`（杜比视界解析）、`Libdav1d.framework`（AV1 解码）与 `Libbluray.framework`（蓝光导航）；底层内嵌完整 FFmpeg 家族（`Libavcodec`, `Libavformat`, `Libavfilter` 等）；保留系统 `AVPlayer` 作为辅助双内核。
- **依赖 SDK 与动态库**：包内动态库达 55 个。集成 `GCDWebServer.framework`（内置本地 HTTP 服务器，用于无线传片与投屏）、`AsyncCoreData.framework`（异步数据库持久化）、Google ML Kit 离线翻译套件，以及 `SwiftyStoreKit` 内购库。
- **规模**：主二进制 61.83 MB，包内文件 1140 个；原生类 718 个，应用源文件 2963 条，内嵌库源文件 345 条。

## 2. 模块分层
- **导航层**：原生多视图控制器路由。代表类：`AppRootViewController`、`RRViewControllerExtension`、`MediaFeedCollectionViewController`。
- **播放引擎层**：基于 Libmpv 封装的流媒体与字幕控制器。代表类：`APTrackManager`（音视频轨道管理）、`AISubtitleTaskManager`（AI 字幕生成调度）、`BakedSubtitles`（压制字幕与硬字幕处理）、`AddSubtitlesOptionsVc`。
- **业务服务层**：云盘挂载、词汇同步与录音调度。代表类：`AliPanTool`（阿里云盘工具）、`AliPanAuthVc`、`BaiduAuthVc`（百度网盘授权）、`ABRecordManager`（A-B 段录音管理）、`DBLocalWordsManager`、`DBNewWordsManager`。
- **数据层**：依托 AsyncCoreData 构建的持久化模型。代表类：`AsyncCoreData`、`AISubsTaskStore`（AI 字幕任务持久化）、`BilingualSubtitleLine`（双语对齐字幕行模型）、`EnWordLookupResult`。
- **UI 层**：播放控制、选区翻译与字幕排版。代表类：`PlayerSettingsViewController`、`SubtitleMaskView`（字幕盲听遮挡视图）、`SelectSubtitleAreaViewController`（选区字幕识别）、`MarkBakedSubtitlesViewController`、`AdjustSubAligmentViewController`（字幕时间轴校准）、`AudioRecorderWave`。

## 3. 能力模块
- **播放与多音轨**：由 `Libmpv` 原生支持 MKV、MP4、FLV、TS 等全格式硬解与杜比视界呈现；通过 `APTrackManager` 暴露多音轨切换接口，支持多语言声道分离。
- **字幕渲染**：依托 `Libass` + `Libplacebo` 实现高质量 ASS 渲染；提供 `BilingualSubtitleLine` 双语字幕对齐；具备 `SubtitleMaskView`（盲听遮挡特训）、`AdjustSubAligmentViewController`（毫秒级字幕轴校准）以及 `MarkBakedSubtitlesViewController`（硬字幕选区标记）。
- **跟读录音与评分**：由 `ABRecordManager` 配合 `AVAudioRecorder` 与 `AudioRecorderWave` 实现单句或 A-B 区间波形可视化录音，支持跟读与原声对比。
- **词汇与记忆算法**：内置 `DBLocalWordsManager` 与 `DBNewWordsManager`；集成 Google ML Kit 离线翻译模型（`MLKTranslateModelManager`），实现离线单词与段落翻译。
- **AI / ASR 能力**：客户端由 `AISubtitleTaskManager` 与 `AISubsTaskStore` 编排任务，通过后端服务上传音视频切片生成时间戳字幕。
- **导入导出**：内置 `GCDWebServer` 支持局域网 WiFi 无线传片；打通百度网盘 OpenAPI 与阿里云盘直链；支持外挂 SRT/ASS 字幕导入与导出（`ExportSubtitlePreviewViewController`）。

## 4. 网络与 API 契约
基于自有云端接口配合第三方网盘开放平台实现云媒体中继，核心自有域名为 `pollykann.com`：
- `https://video.pollykann.com/upload`：音视频切片上传接口，用于云端语音识别与分句。
- `https://video.pollykann.com/subtitle-auto-matching/en` 与 `/zh`：匹配并下载云端双语字幕。
- `https://api.pollykann.com/alipan_auth`：阿里云盘 OAuth 授权换凭证。
- `https://openapi.baidu.com/oauth/2.0/authorize`：百度网盘官方开放平台授权鉴权。
- `https://u.pollykann.com/...`：官方学习资源与样片分发 CDN。

## 6. 对自研的参考价值
1. **摆脱 AVPlayer 局限**：外语精听播放器若想支持 MKV、多音频流切换及 ASS 特效字幕，Pollykann 验证了 `Libmpv + Libass + Libplacebo` 是 iOS 平台最稳健的工业级选型。
2. **场景化功能设计**：`SubtitleMaskView`（盲听遮挡视图）与 `AdjustSubAligmentViewController`（字幕时间轴校准）精准击中外语精听用户的刚需痛点。
3. **网盘与本地传片兼备**：集成 `GCDWebServer` 实现无线 WiFi 传片，搭配阿里云盘与百度网盘挂载，消除 iOS 沙盒下的资源导入壁垒。
