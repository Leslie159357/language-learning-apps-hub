# 21-每日英语听力 深度架构分析报告

## 1. 技术栈判定
- **架构范式**：纯原生 Objective-C 与 Swift 深度混编架构，无跨平台框架引入。内嵌 `OfflineSpeechDownloader_ting_en.appex` 扩展进行后台语音下载。
- **播放内核**：混合多引擎。主音频基于开源 FreeStreamer 演进定制的动态库 `FSPlayer.framework`，结合系统底层 `AVAudioEngine` 与 `AVAudioUnitTimePitch`（变速不变调）；视频及常规流媒体采用 `AVPlayer`、`AVQueuePlayer` 及 `AVPlayerLooper`。
- **依赖 SDK 与动态库**：包内含 4 个动态框架，包括网络传输加速库 `Tquic.framework`（腾讯 QUIC）、音频引擎 `FSPlayer.framework`、广告库 `GDTMobSDK.framework`，并静态内嵌 `onnxruntime` 与 `AFNetworking`。
- **规模**：主二进制 57.55 MB，包内文件 1497 个；原生类 1960 个，源文件路径 1216 条。

## 2. 模块分层
- **导航层**：负责全局路由与车载/扩展屏适配。代表类：`CustomRotationNavigationController`、`EURemotionPlaybackBlockingNavigationController`、CarPlay 适配层 `CPTabBarTemplate`。
- **播放引擎层**：封装音频流控与音视频混音。代表类：`FSPlayer`、`CustomVideoPlayerController`、`EUVideoClipPlayerManager`、`AudioVideoMixManager`、`DubbingSubtitleManager`。
- **业务服务层**：处理学习逻辑与云控协议。代表类：`EUAIChatManager`、`EUAIChatExplainArchiveManager`、`EUFileSpeechDownloadManager`、`CourseExamManager`、`EUPurchaseManager`。
- **数据层**：实体模型与持久化结构。代表类：`AiTransModel`、`AliPanVideoPlayInfoModel`、`ArticleDictationWordModel`、`ArticleWordSpellStatisticModel`、`CourseExamWordModel`。
- **UI 层**：承载沉浸听力、口语跟读与词汇交互。代表类：`ArticleAudioFullScreenController`、`ArticelReaderContentScrollView`、`ArticleDictationView`、`OralPracticeController`、`AIArticleBottomView`。

## 3. 能力模块
- **播放与多音轨**：由 `FSPlayer` 配合 `AVAudioUnitTimePitch` 实现低失真变速变调；通过 `AudioVideoMixManager` 支持人声与伴奏轨混合。
- **字幕渲染**：依托 `DubbingSubtitleManager` 与 `EUMediaSubtitle`，配合 `ArticleContentTimestampTextView` 实现毫秒级逐词逐句高亮滚动。
- **跟读录音与评分**：口语与配音模块（`OralPracticeController`、`DubbingActionViewController`）结合 `AVAudioRecorder` 采集原声，通过 `OralPracticeScoreCell` 进行打分反馈。
- **词汇与记忆算法**：内置欧路词典底座，通过 `ArticleDictionaryViewController` 实现正文划词快查；配合 `ArticleDictationView` 与 `ArticleWordSpellStatisticModel` 建立拼写背词闭环。
- **AI / ASR 能力**：客户端集成 DeepSeek（`https://api.deepseek.com`）进行口语对练；服务端挂载 `https://api.frdic.com/transcribe/recognize` 实现音频智能转录，集成微软云 TTS。
- **导入导出**：打通阿里云盘（`openapi.alipan.com`）与百度网盘 OpenAPI 授权，支持网盘音视频资源挂载与串流播放。

## 4. 网络与 API 契约
依附欧路软件中心化 API 矩阵，核心自有域名为 `frdic.com` 与 `eudic.net`：
- `https://api.frdic.com/transcribe/recognize`：长短音频转录、切片与字幕生成。
- `https://api.frdic.com/api/v2/dicts/search`：欧路词库释义与例句检索。
- `https://api.frdic.com/api/v2/speech/Speak`：云端 TTS 单词与长文本语音合成。
- `https://api.frdic.com/alipan/oauth` 与 `BDPan/oauth`：网盘 OAuth 授权中转。
- `https://api.deepseek.com`：大模型段落答疑与口语生成。

## 5. 源文件拓扑
- **主工程结构**：源码编译路径指向 `/EXTRA/EuSoft/dev/ting/ios/src/Eudic_ting_iOS/`，按业务域模块化划分：
  - `OralPractice/`：口语练习与跟读打分（`OralPracticeController.swift`、`OralPracticeAnswerCell.swift`）。
  - `TingRecommend/`：电台推荐与分级听力（`TingRecommendGuideLevelController.swift`）。
  - `CustomClass/`：通用业务组件（`TingCommonLoadStatusView.swift`）。
- **三方与内嵌库区隔**：源文件列表中混入了大量硬编码路径，主要由内嵌的 ONNXRuntime 静态计算图源码构成（如 `/1/s/onnxruntime/.../conv_op_builder.c` 等百余个 C/C++ 算子文件），与上层 Swift 业务层严格解耦。

## 6. 对自研的参考价值
1. **音频流控选型**：采用 `FSPlayer` 处理低延迟网络音频缓冲，结合底层 `AVAudioEngine` + `AVAudioUnitTimePitch` 处理变速变调，稳定度与内存控制优于纯 `AVPlayer` 封装。
2. **网盘直接集成**：利用 OpenAPI 挂载阿里云盘与百度网盘私有资产作为听力源，大幅缩减自建媒体分发服务器的存储与带宽成本。
3. **词典与听力互通**：划词查询与生词沉淀依托欧路成熟词典库，保证释义准确度与跨应用复用。
