## 1 技术栈 / 播放 / ASR / 扩展

### 1.1 技术栈（证据：LC_LOAD_DYLIB 清单 + 元数据字符串）

纯原生 **Swift + SwiftUI**（`Mora/*.swift` 源码路径成片出现，`_$observationRegistrar` = Observation 框架，`@Observable` 状态机）。无 Flutter / RN / Unity / 无 `Frameworks/` 目录（依赖全部静态链接进主二进制）。

静态链接的关键库：`Alamofire`（`ApiClient.perform(_:method:parameters:headers:)`、`Alamofire.ServerTrustEvaluating` 符号族）、`GRDB`（`GRDB_GRDB.bundle`）、`libsqlite3`。

系统框架：`AVFoundation / AVKit / MediaPlayer / WebKit / SwiftData / StoreKit / NaturalHistory→NaturalLanguage / PhotosUI / AuthenticationServices / SystemConfiguration / Security`。

**关键链接证据（决定分级，务必分清两件事）**：
- **没有 `Speech.framework`**（LC_LOAD 全表里无 Speech，连弱链接都没有），也没有 `SFSpeechRecognizer` / `SpeechAnalyzer` 符号 → **设备端不做 ASR**，转写只能上云。
- **弱链接（LC_LOAD_WEAK_DYLIB）了 `FoundationModels` 与 `_Translation_SwiftUI`** → iOS 26 + Apple Intelligence 设备上**具备端上翻译/生成能力**。对应元数据：`GeneratedSentenceTranslation`、`GeneratedDictionaryEntry`、`GeneratedDictionaryExample`、`PartiallyGenerated`（FoundationModels 流式生成）、`SelectableTextTranslationPresenter`、`Subtitle Translation`、`SupportedTranslationLanguage`；裸字符串 `/System/Library/Frameworks/FoundationModels.framework/FoundationModels`。

⇒ **转写必须上云（吃额度）；翻译/AI 释义可端上完成（不吃额度）。** 这两条决定了第 4 节的分级：字幕的"难的一半"（识别）绕不过，"另一半"（翻译）绕得过。

| 类型 | Product ID | 说明 |

### 2.2 校验链路（客户端只做搬运，不做判定）

参与类型（Swift 元数据）：`VerifyPurchaseRequestBody`、`RestorePurchaseRequestBody`、`CreditPurchaseRequestBody`、`CreditProductDefinition`、`CreditPurchaseViewModel`、`CreditPurchaseSheet`、`StoreTransactionObserver`、`SubscriptionInfo`。

请求体字段（Codable 键名，直接来自二进制）：
```
transaction_jws, transaction_id, original_transaction_id, product_id, receipt
```

流程：
```
StoreKit2 交易 → transaction_jws（JWS 原文）
  → POST {apiBase}/payments/<verify>   （ApiClient.perform(_:method:parameters:headers:)）
  → 服务端调 App Store Server API 验签
  → 回 SubscriptionInfo（权威额度与状态）
恢复购买 → /payments/restore（唯一在字符串表里可见的 payments 路径，16 字节正好超过 Swift 小字符串内联阈值）
```

**关键证据**：客户端二进制里 **没有** 任何 `isPro` / `hasPremium` / `canTranscribe` 这类本地判定属性，只有一个来自服务端 user 对象的布尔 `subscribed`（在 Codable 键名表中出现 3 次）和 `credit`。＝ 会员状态由服务端下发，客户端只读。

### 2.3 额度/点数记账：**服务端记账，单位秒**

`SubscriptionInfo` 的完整字段集（按二进制中连续排布的 Codable 键顺序复原）：

```
subscribed | subid | used_sec | monthly_quota_sec | monthly_remaining_sec
bonus_sec | remaining_sec | oversell_sec | period_start | period_end
reset_at | payment_status | product_id | transaction_id | original_transaction_id
transaction_jws | receipt | restore | credit
```

- `monthly_quota_sec`：套餐月配额（文案 `payment.feature.transcription` = 每月 30 小时 AI 转写 → 108000 秒）
- `used_sec` / `monthly_remaining_sec`：本月已用 / 剩余
- `bonus_sec`：购买的分钟包余额（`settings.transcriptionMinutes.infoBonus` = "另有购买时长 %@ 分钟"）
- `oversell_sec`：**允许透支量** —— 这个字段是服务端为权威账本的最强证据：只有记账方需要"允许小幅超支"，本地计数器不需要
- `reset_at`：服务端下发的月度重置时间点

UI 文案确认记账在服务端：`settings.transcriptionMinutes.info` = "本月已用 %@ / %@ 分钟。"、`settings.credits` = 积分、`settings.creditsMinutes` = "%@ 分钟"。

## 4 可解锁分级

**综合结论：UI/功能入口 = B；云转写额度 = C；总体 B（对"YouTube 有字幕视频的双语化"是真解锁，对"无字幕视频转写"是假解锁）。**

### A 级（纯本地、无服务端判定）—— 部分成立
- 已转写视频的**本地重放**：`VideoTranscript` 已落 GRDB，断网也能看双语字幕（零成本复用）。
- 查词/生词本/AI 释义：`word_lookup_cache` + `FoundationModels`（`GeneratedDictionaryEntry`/`GeneratedDictionaryExample`）端上生成，不吃额度。
- **YouTube 已有字幕的视频**：客户端自己走 `youtubei/v1/player` 取 captionTracks（失败码 `NO_TRANSCRIPT`/`TRANSCRIPTS_DISABLED` 全在客户端），再走 `_Translation_SwiftUI`/`FoundationModels` 端上翻 → 整条链路**不经过 Mora 服务器**。
- 但这些入口的开关仍是 `subscribed`，所以不是干净的 A。

### B 级（服务端下发状态、客户端信任）—— **成立**
证据链：
1. 会员态是服务端 `SubscriptionInfo.subscribed` 布尔，客户端无独立判定（无 `isPro`/`hasPremium` 符号）。
2. 该布尔随 user 对象整体缓存到 `vid.auth.userData`，客户端读缓存即可渲染。
3. 被判定的功能大多是**客户端行为**：`payment.feature.bilingual`（双语字幕显示与**端上翻译**）、`payment.feature.library`（媒体库）、`payment.feature.exercises`（练习题）、`payment.feature.player`（PiP/AB 复读/字幕遮挡）、`payment.feature.lookup`（查词/AI 释义，端上 FoundationModels）、`payment.feature.cloudSync`。
4. API 无签名、无 pinning（Alamofire 仅链接通用 `ServerTrustEvaluating` 协议符号，二进制中无硬编码公钥/证书指纹常量）→ 响应可被 MITM 改写。

⇒ 改 `subscribed`/`credit` 的响应，可把 **UI 层 + YouTube 字幕视频的双语化 + 查词 AI 释义** 全部打开，且这些都是真实功能、不吃额度。

### C 级（服务端强校验 + 计量）—— **只有"转写"这一环**
证据链：
1. 无 `Speech.framework`（连弱链接都没有）→ 没有平台字幕的视频，识别必须服务端。
2. 计量字段 `used_sec` / `monthly_remaining_sec` / `oversell_sec` / `reset_at` 全部由服务端返回，客户端只显示。
3. 客户端不存在本地扣减代码（无 `deduct`/`consume` 类属性，额度只读）。
4. 购买校验用 `transaction_jws` 交服务端验签（App Store Server API），JWS 无法伪造。

⇒ 把 `remaining_sec` 改成大数只会改显示；服务端仍按 `used_sec` 拒绝新转写。

## 5 务实落点

### 5.1 Loon（只改一个域）

```
[Host]
v1.kkapp.xin

[Script]
# 主规则：整域响应统一过一遍（路径未知也能生效，因为字段名是全局唯一的）
http-response ^https:\/\/v1\.kkapp\.xin\/api\/ script-response-body https://your.gw/mora_sub.js
```

（可选）确认具体路径后收紧范围；`/payments/restore` 是唯一静态可见的购买相关路径，其余 profile 路径 ≤15 字节被内联、静态不可见，**不要按猜的路径写规则**，用上面的整域规则更稳。

脚本要做的（JSON 层，递归改键，路径不必精确匹配，凡是带这些键的响应都改）：

```js
const KEYS_TRUE = ["subscribed"];                       // → true
const KEYS_NUM  = ["credit","remaining_sec","monthly_remaining_sec","bonus_sec","monthly_quota_sec"];
// subscribed: false → true
// payment_status: 非 active → "active"
// remaining_sec / monthly_remaining_sec / credit → 999999
// oversell_sec 保持原值（避免客户端做过冲校验）
```

注意点：
- `period_end` / `reset_at` 若是过去时间，客户端会自己判定过期 → 一并推到未来（+30 天）。
- 只改响应、不改请求。API 无签名，所以不需要动 body。
- `vid.auth.userData` 是**缓存**：首次启动前改响应才会写入正确缓存；已缓存的话清一次 App 数据或让 App 走 `refreshSilently(api:)`。

### 5.2 额度制结论（说清楚）

**Mora 的额度是服务端记账，本地不扣减。**
- 判定依据：`used_sec`（服务端返回的已用量）、`oversell_sec`（服务端才需要的透支容忍字段）、`reset_at`（服务端月度重置点），客户端既无本地计数器也无扣减函数。
- 因此 Loon 改 `remaining_sec` **只能骗 UI**，第 N 次转写照样被服务端按账号 `used_sec` 拒。
- **但**"双语字幕"不等于"转写"：字幕 = 识别 + 翻译。识别必须上云（无 Speech 框架），**翻译可以端上做**（`FoundationModels` + `_Translation_SwiftUI` 弱链接）。所以对 **YouTube 已有英文字幕的视频**，Loon 改 `subscribed` 后是**真解锁**——客户端自己抓字幕轨（`youtubei/v1/player`），端上翻译，全程零额度。
- 对**没有字幕的本地/其它视频**，识别这一环绕不过：要么本地补丁把转写改走自建 ASR（Whisper），要么直接给 GRDB 灌 `VideoTranscript` 行。这已经不是"解锁会员"，而是"自己造数据"。

### 5.3 若要走本地补丁（越狱/TrollStore 侧）

优先级：
1. Hook `UserStore.userData` 的 decode（把 `subscribed` 置 true）→ 一行覆盖全部 UI 门。
2. Hook `ApiClient.perform(_:method:parameters:headers:)` 的返回体，做同样的 JSON 注入（等价于 Loon，但离线也生效）。
3. 不要硬塞 ObjC Hook：纯 SwiftUI + Observation（iOS 17+），传统 `%hook` 会因 `@Observable` 存储属性布局失败。按仓库规范用 LoadControl 弱加载 + Swift 侧符号钩。

## 附：无法取证项（诚实标注）

- `/payments/` 下的 verify 具体路径：长度 ≤15 字节被 Swift 小字符串优化内联到指令立即数，`strings` 不可见；只能靠 Ghidra 反编译 `ApiClient` 取。对 Loon 方案无影响（响应侧按 host 匹配即可）。
- 免费用户是否有"每月赠送 N 分钟"：二进制中未见独立常量，只有 `monthly_quota_sec` 由服务端下发，故免费额度也在服务端。
