# 30-语幕 Mora 深度架构分析报告

## 一、技术栈与播放内核

- **基础规格**：应用 Bundle ID 为 `com.kkapp.mora`，版本号 `1.3`，最低系统要求 iOS `17.0`。主二进制体积 `10.95 MB`，无独立动态库，包含 `VideoTransAction` 与 `VideoTransShare` 两个应用扩展。
- **技术栈**：采用原生 Swift / Objective-C 混合开发。网络层集成开源库 Alamofire，数据存储基于 GRDB.swift 构建 SQLite 本地数据库，并启用 FTS5 全文检索引擎。
- **播放内核与音视频管线**：回放内核基于苹果原生 `AVPlayer`、`AVPlayerItem` 与 `AVPlayerLayer`，封装了 `PlayerModel`、`PlayerContainerUIView`、`PlayerLayerView`。具备画中画保活机制 `PlayerPiPKeepAlive`、锁屏/控制中心播控 `PlayerNowPlayingController`、手势音量与垂直交互监听 `PlayerVerticalControlMonitor`。针对 YouTube 资源提供 `YouTubeEmbedPlayerView` 网页容器。音频抽取由 `AudioExtractionService` 驱动 `AVAssetExportSession` 与 `AVAssetReader` 实现。

## 二、模块分层

1. **表现层（UI / Views）**：基于 SwiftUI 与 UIKit 混合构建。主要界面包含 `ContentView`、`PlayerContainerUIView`、`PlayerBottomController`、`SubtitleCustomizeView`、`CustomVocabularyListView`、`FolderListView`、`VideoChatView`。
2. **状态与业务会话层（ViewModels & Coordinators）**：负责转录轮询、跟读生命周期与 AI 会话。代表类包括 `ContentViewModel`、`TranscriptViewModel`、`TranscriptPollCoordinator`、`ExercisePollCoordinator`、`VideoChatViewModel`、`CreditPurchaseViewModel`、`LoginViewModel`。
3. **AI 对话与网络传输层**：
   - **AI 交互客户端**：`VideoChatSession`、`VideoChatSessionStore`、`VideoChatWebSocketClient`。
   - **网络与文件上传**：`ApiClient.swift`、`AuthTokenBuilder.swift`、`AudioExtractionService`、`HTTPMultipartUploadProvider`、`DownloadRequest`。
4. **数据持久化与引擎层（GRDB 体系）**：
   - 数据库基础设施：`DatabasePool`、`DatabaseQueue`、`DatabaseMigrator`、`FTS5TableDefinition`。
   - 数据实体与存取：`Record`、`FetchableRecordDecoder`、`VideoStorage`、`VideoLibrary`、`CustomVocabularyStore`。

## 三、能力模块

- **视频导入与解析**：支持系统 Share/Action 扩展从相册或三方 App 导入视频；本地由 `VideoLibrary` 与 `VideoStorage` 执行分级存储与沙盒流转；支持 YouTube 视频解析与内嵌播放；音频流通过 `AudioExtractionService` 快速提取为独立音频。
- **字幕与翻译**：提供字幕样式定制（`SubtitleAppearanceSettings`、`SubtitleCustomizeView`）与视频遮罩遮挡原文字幕（`VideoMaskSettings`）；通过 `TranscriptPollCoordinator` 轮询云端 ASR 生成的字幕结果；点词查询通过 `SelectableTextTranslationPresenter`、`CustomVocabularyStore` 与 `WordPronunciationPlayer` 联动，发音接入百度翻译 TTS 与系统 `AVSpeechSynthesizer`。
- **跟读**：利用 `ListLoopAdvanceCountdown` 提供句级循环倒计时；`ExerciseSession` 与 `ExercisePollCoordinator` 编排跟读练习过程，评分记录写入本地 SQLite 存储。
- **云盘/协议接入**：未接入公网 WebDAV/SMB/网盘服务；仅包含基于 iCloud 的私有同步（`ICloudSyncSettings`）。
- **媒体库管理**：采用文件夹树形分类体系，提供 `FolderListView`、`FolderDetailView`、`ExerciseSourceFolderPickerView` 管理多级视频文件夹。

## 四、网络与 API 契约

- **自有域名与核心接口**：
  - `kkapp.xin`（自有服务域名）：核心 API 入口为 `https://v1.kkapp.xin/api`，承载用户凭证（`AuthTokenBuilder.swift`）、字幕转录任务提交与元数据同步。
- **依赖域名与第三方接口**：
  - **临时音视频切片上传**：`https://tmpfile.link/api/upload`。
  - **语音合成**：`https://fanyi.baidu.com/gettts`。
  - **YouTube 数据与播放**：`https://www.youtube.com/youtubei/v1/player?key=`、`youtubei/v1/browse`、`iframe_api`、`oembed`。
  - **文档服务**：`kksoftservice.github.io`。

## 五、对自研的参考价值

1. **视频 AI 问答 WebSocket 架构**：通过 `VideoChatWebSocketClient` 建立双向长连接，结合视频上下文与时间戳进行流式 AI 问答交互，为自研 AI 伴学和音视频理解功能提供了标准的通信原型。
2. **移动端 GRDB + FTS5 高性能检索方案**：依托 GRDB 的 `DatabasePool` 并发读写与 SQLite FTS5 倒排索引，使得长视频中数千句字幕文本与自定义生词本能够实现毫秒级即时搜索与高亮匹配。
3. **音轨分离切片上传链路**：客户端先行通过 `AVAssetExportSession` 剥离视频音轨并压缩，通过 `tmpfile.link` 或自有接口分片上传，相比直接上传全量高清视频，节省 90% 以上的上行带宽和传输时间。
