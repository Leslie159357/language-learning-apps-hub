## 2. 状态机梳理
- **状态来源**:
  - **混合校验模式**: StoreKit 2 (`Transaction.currentEntitlements`) 负责客户端交易监听；`UserSyncService` 将 App Store JWS 凭证上报给自建 API 后端进行二次鉴权校验。
  - **权威来源**: 服务端返回的 `VerifyAppleIAPResponse` 与 `UserSync` 响应中的 `isPro` 与 `expiresAt` 字段。
  - **本地兜底**: 客户端具有离线缓存过期检测 `isOfflineExpired`，断网时比对最后同步的本地到期时间戳。
- **额度计数落点与判定链**:
  - 课程按单元设限。未购买用户尝试请求 Pro 单元内容时，服务端直接返回错误码 `COURSE_ACCESS_DENIED`。
  - 判定链:
    1. 用户选择课程单元 -> 触发 `canDownload` / `accessLevel` 检查。
    2. 检查当前内存或本地缓存中的 `user.isPro` 状态以及 `expiresAt` 是否大于当前时间。
    3. 若无有效 Pro 权限，禁止发起音频单元下载，弹出订阅购买引导；
    4. 若有有效 Pro 权限，调用 `UnitDownloader` 获取素材并进入播放器引擎。

## 3. 契约字段
- **服务端域名**:
  - 主域名: `https://api-cn.echolangs.cn`
  - 备用/全球网关: `https://richapi.echolangs.com`
- **主要端点**:
  - `POST /api/mobile/verify_apple_iap`
  - `POST /api/mobile/user/sync`
- **请求字段**:
  - `userId`: 字符串（Clerk 用户 ID）
  - `productId`: 字符串 (`"com.echolangs.pro.monthly.v2"` 或 `"com.echolangs.pro.yearly"`)
  - `transactionId`: 字符串
  - `originalTransactionId`: 字符串
  - `expiresDateMs`: 数字（毫秒时间戳）
  - `jwsRepresentation`: 字符串（Apple StoreKit 2 签名凭证）
- **响应字段 (`VerifyAppleIAPResponse`)**:
  - `success`: 布尔值 `true | false`
  - `plan`: 字符串取值域 `["free", "pro", "pro_monthly", "pro_yearly"]`
  - `isPro`: 布尔值 `true | false`
  - `expiresAt`: 数字（毫秒时间戳）或 `null`
  - `message`: 提示文案，如 `"兑换成功！已为你解锁 PRO 权益"`
  - `error`: 错误信息或 `null`
